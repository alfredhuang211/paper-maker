# paper-maker

**可打印的 A4 小工具生成器合集。** 主页面列出各种生成子应用，打开网页 → 调好参数 → 点打印，得到一张可以直接用的 A4 练习纸。界面与打印内容支持中英文切换（右上角切换，默认跟随浏览器）。

纯前端静态站，托管在 GitHub Pages：无账号、无广告、无后端、不上传数据。

> **状态：v0.5 · M1–M2 核心功能 + 通用多张/PDF（三个工具可用）。**
> 已实现主页面子应用列表、中英切换、A4 预览/打印、统一设计系统与响应式布局；后续继续补齐 M3 体验项。

## 为什么做这个

家长和老师经常需要「随手可打印」的练习材料，但现有站点普遍存在这些问题：

- 广告多、有水印、要注册登录，甚至按页收费；
- 参数不可调（难度、题量、排版），拿到的练习页不一定适合眼前的孩子；
- 排版不适配 A4，打印出来留白奇怪、需要手动缩放；
- 练习页和答案不分离，重复练习只能反复下载。

而练习页天然适合纯前端生成：**内容由参数决定、无需账号、无需存储、可无限次生成、可离线**。把生成逻辑放在浏览器里，既省服务器成本，也天然保护隐私。

## 设计原则

1. **A4 优先**：一切以打印出来的纸面效果为验收标准，而不是屏幕截图好看。
2. **零门槛**：打开即用，无登录、无广告、无弹窗；参数用默认值也能直接打印。
3. **可调可控**：难度、题量、版式、线条粗细均可调；随机结果可用「种子」复现。
4. **答案分离**：练习页与答案页分开，答案可关闭。
5. **隐私友好**：不收集、不上传；所有生成在本地完成。
6. **可扩展**：新增工具 = 一份参数定义 + 一个生成引擎 + 一个渲染器。
7. **中英双语**：界面与打印内容均支持中文/英文；右上角切换，默认跟随浏览器语言。
8. **清淡留白**：中性色 + 单一强调色；大间距、少边框，避免视觉噪音。
9. **全站一致**：所有子应用共用同一套设计 tokens 与组件库；设置/选择控件外观完全一致，禁止各做一套。
10. **自适应**：手机、平板、桌面浏览器均可用；无横向滚动，触控目标 ≥ 44px。

## 技术栈

- **构建**：Vite + TypeScript
- **包管理**：npm（Node.js 22+）
- **UI**：React（函数组件）+ CSS（含打印样式）；图形优先用 SVG，保证打印为矢量
- **国际化**：轻量 i18n（中英文案表 + 浏览器语言检测 + localStorage），默认跟随浏览器、右上角切换
- **设计系统**：CSS 变量 design tokens + 自研共享组件库；子应用不写私有控件样式
- **状态**：轻量（URL 参数 + 本地状态），不引入重型状态库
- **导出**：初版使用浏览器原生打印（「另存为 PDF」）；P2 评估 `pdf-lib` 客户端导出
- **部署**：GitHub Actions → GitHub Pages（静态产物）
- **测试**：Vitest（生成引擎单测）；打印/响应式使用 Playwright 脚本做过验收，后续纳入 CI

> 选型理由与备选方案见 [技术方案](docs/05-architecture.md)。

## 本地开发

```bash
npm install
npm run dev       # 本地开发
npm test          # 单元测试
npm run build     # 构建静态产物到 dist/
npm run preview   # 预览构建产物
```

> 构建产物通过 GitHub Actions 发布到 GitHub Pages（`.github/workflows/deploy.yml`）。项目站点路径为 `/paper-maker/`，绑定自定义域名时需把 `vite.config.ts` 的 `base` 改为 `/`。
