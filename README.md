# paper-maker

**可打印的 A4 小工具生成器合集。** 打开网页 → 调好参数 → 点打印，得到一张可以直接用的 A4 练习纸。

纯前端静态站，托管在 GitHub Pages：无账号、无广告、无后端、不上传数据。

## 为什么做这个

家长和老师经常需要「随手可打印」的练习材料，但现有站点普遍存在这些问题：

- 广告多、有水印、要注册登录，甚至按页收费；
- 参数不可调（难度、题量、排版），拿到的练习页不一定适合眼前的孩子；
- 排版不适配 A4，打印出来留白奇怪、需要手动缩放；
- 练习页和答案不分离，重复练习只能反复下载。

而练习页天然适合纯前端生成：**内容由参数决定、无需账号、无需存储、可无限次生成、可离线**。把生成逻辑放在浏览器里，既省服务器成本，也天然保护隐私。

## 设计原则

1. **A4 优先**：一切以打印出来的纸面效果为验收标准，而不是屏幕截图好看。
2. **零门槛**：打开即用，无登录、无广告、无弹窗；参数用默认值也能直接打印。
3. **可调可控**：难度、题量、版式、线条粗细均可调；随机结果可用「种子」复现。
4. **答案分离**：练习页与答案页分开，答案可关闭。
5. **隐私友好**：不收集、不上传；所有生成在本地完成。
6. **可扩展**：新增工具 = 一份参数定义 + 一个生成引擎 + 一个渲染器。

## 技术栈（拟）

- **构建**：Vite + TypeScript
- **UI**：React（函数组件）+ CSS（含打印样式）；图形优先用 SVG，保证打印为矢量
- **状态**：轻量（URL 参数 + 本地状态），不引入重型状态库
- **导出**：初版使用浏览器原生打印（「另存为 PDF」）；P2 评估 `pdf-lib` 客户端导出
- **部署**：GitHub Actions → GitHub Pages（静态产物）
- **测试**：Vitest（生成引擎单测/快照）+ Playwright（打印 PDF 视觉回归）

> 选型理由与备选方案见 [技术方案](docs/05-architecture.md)。M1 开始前可再确认。
