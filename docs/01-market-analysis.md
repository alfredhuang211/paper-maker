# 01 · 需求分析

> 版本：v0.2 · 状态：草案 · 日期：2026-11-09
> 关联文档：[PRD](02-prd.md) · [打印规范](03-print-spec.md) · [路线图](06-roadmap.md)

## 0. 结论摘要（TL;DR）

1. **需求真实且高频**：家长、小学教师、托管机构需要大量「可打印的 A4 练习纸」，现有工具要么有广告/水印/注册门槛，要么只能下载固定 PDF、无法调参。
2. **供给存在明显空档**：市场呈两极——「免费 + 广告 + 粗糙」（Math-Aids 类）与「订阅 + 精致但封闭」（Twinkl 类）；**免费、无广告、参数可控、A4 原生**的中间态几乎空缺。
3. **技术路径成立且成本低**：练习页内容可由参数完全决定，纯前端生成即可；GitHub Pages 免费托管，无后端、无数据库、无账号，隐私风险最低。
4. **建议首批聚焦三个高频工具**：涂色页、口算页、舒尔特方格。三者共用「参数 → 生成 → A4 打印」同一套框架，能验证平台化思路。
5. **差异化不靠「更多工具」**，靠四件事：A4 原生与打印校准、可复现的随机种子、练习页/答案页分离、中文教材场景（人教版/竖式/字帖）。

## 1. 背景与问题定义

### 1.1 现象

- 小学生每天的课后练习、口算打卡、注意力训练，都需要**纸质材料**；屏幕练习无法替代书写与打印场景。
- 家长通常的获取方式是：微信群转发 PDF、网盘合集、电商购买电子版、搜索引擎找免费站点——质量参差，且大量重复。
- 教师/托管机构需要**按班级、按难度、按题量**批量出卷，现成 PDF 很难恰好匹配。

### 1.2 现有方案的问题

| 问题 | 具体表现 | 影响 |
| --- | --- | --- |
| 广告与诱导 | 免费站广告密集，部分站点甚至禁止广告拦截 | 体验差，儿童使用时不可控 |
| 注册与付费墙 | 预览免费、下载要注册/订阅 | 临时需求被迫付费 |
| 不可调参 | 只有固定卷册/固定难度，不能改题量、数值范围、字号 | 无法匹配孩子当前水平 |
| 不适配 A4 | 大量美站默认 US Letter，A4 打印被裁切或缩放 | 打印返工，浪费纸 |
| 无答案页 | 答案另售或不提供 | 家长批改成本高 |
| 随机质量差 | 题目重复、减法出负数、除法不整除、0 因子 | 练习无效甚至误导 |
| 移动端不可用 | 表格溢出、按钮太小 | 手机上无法完成配置 |

### 1.3 为什么现在做

- 浏览器能力足够：SVG、CSS `@page`、`window.print()`、PWA 已成熟，**生成与导出都可以在本地完成**；
- GitHub Pages 免费、稳定、自带 HTTPS，静态站部署成本趋近于零；
- 家用打印机普及，「在家打印练习纸」已是常态；
- 主流工具老龄化明显（大量站点是 2010 年代设计），存在体验代差机会。

## 2. 目标用户与场景

### 2.1 用户画像

| 画像 | 典型特征 | 核心诉求 | 使用频率 |
| --- | --- | --- | --- |
| **小学家长（主）** | 孩子 1–4 年级；家用喷墨/激光打印机；辅导作业 | 快速出一页合适的口算/涂色，最好带答案 | 每周 2–5 次 |
| **小学教师** | 教 1–6 年级；办公室打印；需要按班级出卷 | 题量/难度可控、可批量、版式统一 | 每周 1–3 次，集中 |
| **托管/教培老师** | 带多个孩子、混龄 | 批量生成不同难度、成本低 | 高频、批量 |
| **注意力训练者（成人/老人）** | 用舒尔特方格做日常训练 | 打印规格标准、有训练方法说明 | 每日/隔日 |
| **亲子活动家长** | 周末陪孩子涂色、玩迷宫 | 线稿好看、线条适合幼儿、可打印 | 周末为主 |
| **海外/华裔家庭（英文）** | 使用英文界面；孩子做数学/涂色练习 | 英文界面与英文练习纸、A4 打印 | 每周 1–3 次 |

> 非目标用户（首版）：需要云端班级管理、作业批改、学情分析的机构；需要 AI 生成写实插画的用户。

### 2.2 核心场景（用户故事）

1. **口算打卡**：晚上 8 点，家长打开手机/电脑，选「二年级 · 100 以内加减 · 20 题 · 含答案」，打印一页，孩子 5 分钟做完，家长翻到答案页批改。
2. **课堂小测**：老师早上到办公室，选「三年级 · 表内乘除 · 40 题 · 4 列」，一次打印 40 份（同一份题），或打印 3 个不同版本防止抄袭。
3. **周末涂色**：家长选「曼陀罗 · 中等复杂度 · 粗线条」，打印 2 张，孩子涂色；需要线条闭合、区域足够大、不费墨。
4. **舒尔特训练**：家长打印一张 5×5，孩子每天计时一次，在页眉记录日期与用时；一周后打印一张新的（同规格、不同排列）。
5. **错题重练**：孩子上次口算错了 4 题，家长用「同种子重新生成」或「错题再练」功能，得到同类型新题。
6. **英文用户**：浏览器为英文的家长首次打开站点，界面自动显示英文；打印出的标题、说明、记录栏均为英文，无需手动配置。

## 3. 需求归纳

| 用户痛点 | 需求 | 对应产品能力 |
| --- | --- | --- |
| 找资源耗时、质量不可控 | 即时生成、所见即所得 | 参数面板 + A4 实时预览 |
| 难度不匹配 | 难度可调、按年级预设 | 数值范围/复杂度/规格参数 |
| 打印被裁切、缩放 | A4 原生排版 | mm 布局、`@page`、校准页 |
| 批改麻烦 | 答案可分离 | 答案页开关、独立分页 |
| 重复练习 | 随机 + 可复现 + 错题重练 | 随机种子、重新生成、错题再练 |
| 批量需求 | 一次多页/多份 | 批量生成、多版本 |
| 广告/注册/隐私 | 零门槛、纯本地 | 无账号、无追踪、无后端 |
| 英文用户需要英文界面与练习纸 | 中英双语 | 语言切换（右上角）+ 打印内容本地化 + 默认跟随浏览器 |
| 效果宣传不可信 | 克制、有依据的说明 | 舒尔特训练说明注明证据边界 |

## 4. 竞品与替代方案

> 下表依据竞品公开页面与公开资料整理（2026-11），价格与条款可能变化，以官网为准。标注「推断」的为经验判断，尚未逐条验证。

### 4.1 竞品扫描

| 产品 | 类型 | 可调参数 | 商业模式 | 优点 | 短板 |
| --- | --- | --- | --- | --- | --- |
| [WorksheetWorks](https://worksheetworks.com/) | 数学/英语/迷宫/手写等数十类 | 题型、范围、行列、字体 | 年费约 $14.95 | 参数细、PDF 干净无水印 | 界面老旧、移动端差（推断） |
| [Math-Aids](https://www.math-aids.com/) | 数学，主题极多 | 运算、位数、进退位、题量、字号 | 免费 + 广告；去广告付费 | 自动答案页、K-12 覆盖全 | 广告密集、版式粗糙、禁止广告拦截 |
| [Education.com](https://www.education.com/) | 练习页 + 课程 | 年级/学科筛选 | Freemium 订阅 | 内容量大、分级清楚 | 下载需注册、免费额度少（推断） |
| [Twinkl](https://www.twinkl.com/) | 全学科资源 + 自制工具 | 模板、字体、线稿 | 订阅制 | 资源海量 | 付费墙重、非英制课程适配差（推断） |
| [Krazydad](https://krazydad.com/) | 数独/逻辑/迷宫等 | 按卷册选难度 | 完全免费、无注册 | 印刷级排版、答案齐全 | 非实时参数化、无涂色/口算 |
| [edHelper](https://www.edhelper.com/) | 数学/阅读/写作 | 年级、题量 | 订阅制 | 覆盖广 | 口碑差（公开评分约 2.4/5）、计费投诉多 |
| [SchulteLab](https://schultelab.org/) | 舒尔特在线训练 + 打印 | 3×3–10×10、字母/蜂窝/正逆序 | 免费、无需注册 | 规格最全、有循证说明 | 无 A4 排版调参、偏屏幕训练（推断） |
| [mazegenerator.net](https://www.mazegenerator.net/) | 迷宫 | 尺寸、形状、难度、是否带解 | 免费（署名） | 参数直观、可出 PDF/SVG | 样式单一（推断） |
| 汉字字帖生成器（多个小站/小程序） | 田字格/描红 | 字表、格子、字号、遍数 | 免费 + 广告（推断） | 中文刚需 | 广告多、导出质量参差（推断） |
| AI 涂色页站点（如 coloringpages.tools） | AI 生成线稿 | 提示词、风格 | 免费 + 授权分层 | 出图快、授权写清楚 | 质量不稳、位图不可调线宽（推断） |

### 4.2 分析结论

1. **两极分化**：一头是「免费 + 广告 + 粗糙」，另一头是「订阅 + 精致但封闭」；**中间态供给稀缺**。
2. **参数化程度是分水岭**：体验最好的站点（Krazydad、WorksheetWorks）都强在「内容质量 + 印刷级排版」，但交互与移动端普遍落后。
3. **涂色页与口算页的免费供给最多，但质量最不稳定**；舒尔特方格偏屏幕训练，打印版式普遍不讲究。
4. **中文教材场景（人教版进度、竖式、田字格）几乎无人系统覆盖**，是最难被英文站复制的差异点。
5. **双语是低成本的受众扩展**：中英双语可同时覆盖中文家庭与英文用户；英文站普遍缺中文教材场景，中文站普遍缺完整英文体验，双语供给同样稀缺。

### 4.3 替代方案

| 替代方案 | 用户为什么用 | 我们的差异 |
| --- | --- | --- |
| 微信群/网盘 PDF 合集 | 免费、现成 | 可调参、无重复、不占存储 |
| 电商购买电子版 | 质量有保证 | 免费、可无限生成 |
| AI 生成图片 | 样式新颖 | 矢量线稿可打印、可调线宽、可复现 |
| 老师手工出题 | 最贴合班级 | 省时间、可批量、格式统一 |

## 5. 可行性与约束

### 5.1 技术可行性

- 练习页内容（数字、字母、几何图形、文字）**可由算法与参数完全生成**，不需要服务端与 AI 推理；
- SVG 渲染天然矢量，打印清晰；CSS `@page` + 浏览器打印可按 A4 精确排版；
- 纯静态站可部署在 GitHub Pages，零服务器成本；
- 生成引擎是纯函数，易测试、易复现（种子）。
- 风险点：浏览器打印的页边距/页眉页脚控制力有限，需要以「校准页 + 明确指引 + 预览」弥补（见[打印规范](03-print-spec.md)）。

### 5.2 内容与版权

- 所有线稿、题目、方格**由程序生成**，不抓取第三方素材；字体需使用可商用授权的开源字体（如思源黑体/Noto Sans SC、霞鹜文楷等），图标使用 MIT/CC0 图标库。
- 生成物授权：明确声明用户可自由使用（含商用），对标竞品「授权分层写清楚」的做法，作为信任卖点。
- 不使用任何受商标/形象权保护的卡通角色；主题限定为抽象几何、自然元素、通用节日符号。

### 5.3 合规与伦理

- **儿童隐私**：不做账号、不上传、不采集；若未来加统计，必须匿名、可关闭、明确说明。
- **效果宣称**：舒尔特方格只写「用于注意力/视幅的日常练习」，不承诺「提升智商/成绩/治疗 ADHD」；引用研究需注明出处与局限（相关研究对远迁移的支持有限）。
- **无障碍**：基础键盘操作、对比度、打印黑白可辨识。

### 5.4 成本

- 托管：GitHub Pages 免费额度足够（站点 1GB、月流量 100GB 软限制）；
- 维护：纯前端，无数据库、无 API、无运维轮班。

## 6. 风险与对策

| 风险 | 影响 | 可能性 | 对策 |
| --- | --- | --- | --- |
| 浏览器打印差异导致 A4 错位 | 高 | 中 | mm 布局 + 校准页 + 浏览器兼容清单 + 打印指引 |
| 生成内容质量不稳定（线稿丑/题目重复） | 高 | 中 | 生成规则约束 + 单测/快照 + 人工样张评审 |
| 工具同质化、缺乏留存 | 中 | 高 | 种子复现、错题重练、孩子档案、批量与合集工作流 |
| 版权/字体/商标问题 | 高 | 低 | 只用开源字体与自生成图形，建立素材台账 |
| 项目范围膨胀 | 中 | 高 | 严格 P0 边界，先三件套跑通再扩展 |
| 无用户反馈渠道 | 中 | 中 | GitHub Issues 模板 + 页脚反馈入口（P1） |
| Pages 服务不可用/被墙 | 中 | 低 | 纯静态可镜像部署；提供离线 PWA（P2） |

## 7. 结论与建议

**值得做**，但必须**克制范围**：

1. 首版只做三个工具（涂色、口算、舒尔特），共用同一套「参数 → 生成 → A4 打印」框架；
2. 把「A4 原生 + 打印校准」和「可复现种子」做成明确卖点，而不是堆工具数量；
3. 先服务中文小学场景（人教版进度、竖式、字帖），这是差异化护城河；
4. 不引入账号、后端、AI 生成，守住「零门槛、纯本地、免费」的定位；
5. 用 M1 的一个最小工具验证打印链路后，再并行开发三件套；
6. 界面与打印内容提供中英双语（默认跟随浏览器、右上角切换），以近零内容成本扩大受众。
