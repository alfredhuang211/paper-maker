# 08 · 可打印内容分类目录（竞品汇总）

> 版本：v0.1 · 状态：草案 · 日期：2026-11-09
> 用途：汇总已分析竞品**实际能生成的可打印内容**，作为 paper-maker 功能规划与差异化的输入。本文不代表 paper-maker 全部都要做。
> 关联：[需求分析](01-market-analysis.md) · [PRD](02-prd.md) · [设计系统](07-design-system.md)

## 0. 说明

- 收录范围：竞品公开页面/仓库中可生成、可打印的**纸面内容**（练习纸、涂色页、方格、计划表、派对物料等）。
- 不收录：纯屏幕游戏、纯计算器、纯 PDF 编辑工具、纯设计工具（除非其输出是可打印练习页）。
- 分类按「主要用途」划分，部分内容可跨类（如「阅读记录」既是教学也是生活管理），不重复计数。
- 统计为**内容类型数**，不是竞品 SKU 数；同一类型下不同难度/规格不单独计数。

## 5. 对 paper-maker 的映射

### 5.1 首批三件套对应内容

| paper-maker 工具 | 覆盖的内容类型 |

| 涂色页 | C01 主题涂色页、C02 姓名涂色页、C06 程序化曼陀罗/对称线稿（差异化） |
| 口算页 | A01 口算横式、A02 竖式、A03 混合运算、A04 填空、A11 有余数除法、A14 按年级、A15 速算卡 |

### 5.2 候选扩展优先级

| 优先级 | 内容 | 理由 |
| --- | --- | --- |
| P1 | A06 数独、A07 迷宫、B04 田字格字帖、B06/B07 字母/单词字帖、B08 单词闪卡、B11 作文纸 | 与现有「纸张 + 生成器」框架高度复用，需求明确 |
| P2 | A08 找词、A09 填字、A10 字母乱序、A12 数学谜题、B01–B03 汉字听写/拼音/描红、B05 数字描红、B09 词汇练习 | 中文/英文练习扩展，需更多内容规则 |
| P3 | D05–D08 Stroop/数字广度/连线/反应速度、E03–E09 课堂物料、H01/H05 标签/作文纸 | 与核心练习页邻近，按用户反馈决定 |
| 暂不做 | F 计划与生活、G 活动与派对、H02/H03 发票/日历、I AI 生成类 | 偏离「学习练习页」定位，或与程序化/可复现定位冲突 |

### 5.3 差异化机会（来自目录的空白）

1. **程序化涂色页**（C06）：竞品以固定模板或 AI 位图为主，缺少「复杂度/线宽/区域数/种子可调」的矢量线稿。
2. **中文教材对齐 + 中英双语**：AulaFun 只做西班牙语，PrintMigo 多语言但偏通用，中文教材进度仍是空白。
3. **打印工作流**：100mm 校准、mm 布局、省墨、批量、答案页分离——单点竞品有，但作为「全站标准」的少。
4. **注意力训练打印包**：SchulteLab 很强但单一；把舒尔特 + 记录表 + 训练说明 + 每日挑战做成「可打印训练包」，仍有空间。
5. **开源 + 纯静态 + 离线**：公开项目中缺少「多工具、双语、打印优先、统一设计系统」的完整实现。

## 6. 统计与观察

- 一级分类：9 个；内容类型：约 100 项（按主要用途归类，跨类不重复计数）。
- 覆盖最密集：A 数学、B 语言书写、E 教学课堂、F/G 计划与派对。
- 覆盖最稀疏：D 注意力训练（集中在 SchulteLab）、C 程序化涂色（几乎空白）。
- 商业站（S10）强在内容量与 SEO；综合工具站（S1）强在广度与多语言；专精站（S4）强在单点深度；开源项目（S8）强在可复用代码，但产品化与打印体验普遍不足。
