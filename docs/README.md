## 文档约定

- **需求编号**：`G-xx` 通用能力、`CP-xx` 涂色页、`MW-xx` 口算页、`SG-xx` 舒尔特方格、`NFR-xx` 非功能需求。
- **优先级**：`P0` 首个可用版本必须有；`P1` 首个正式版前后补齐；`P2` 后续增强/探索。
- **状态**：`草案` → `评审中` → `已确认` → `已实现`。当前所有文档为**草案（v0.2）**。
- **单位**：版式一律用毫米（mm），字号用 pt，屏幕预览用 px 并注明换算。
