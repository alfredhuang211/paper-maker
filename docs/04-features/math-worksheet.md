# 04b · 功能规格：口算页生成器

> 版本：v0.3 · 状态：草案 · 日期：2026-11-09
> 关联：[PRD](../02-prd.md) · [打印规范](../03-print-spec.md) · [技术方案](../05-architecture.md)

## 1. 目标与价值

为小学家长、教师提供**按年级/数值范围/题型**生成的口算练习页，自动配套答案，解决「找题、难度不匹配、批改麻烦」三个高频问题。

**成功标准**：家长选一个年级预设，30 秒内打印出「题量合适、答案正确、书写空间足够」的一页；老师能批量出多份。

## 4. 功能需求

### MW-01 运算类型与题型（P0）

| 类型 | 说明 | 优先级 |
| --- | --- | --- |
| 加法 | `a + b = ____` | P0 |
| 减法 | `a − b = ____`，结果非负 | P0 |
| 乘法 | `a × b = ____` | P0 |
| 除法 | `a ÷ b = ____`，整除 | P0 |
| 混合 | 随机组合以上四种 | P0 |
| 四则混合运算 | `a + b × c` 等，含优先级 | P1 |
| 比大小 | `3 + 5 ○ 9` | P1 |
| 填空 | `3 + ○ = 8`、`○ × 4 = 12` | P1 |
| 竖式 | 竖式排版加减乘除 | P1 |
| 应用题 | 模板化文字题 | P2 |

**验收**：每类题型可单独选择；混合模式四种运算比例可调（默认均等）。

**填写内容**（两个独立勾选项，可同时勾选）：

- 默认「填写答案」：`12 + 7 = ____`，填写得数；
- 「填写算数」：整个算式包含得数与一个数，填写另一个数，例如 `12 + ____ = 19` 或 `____ + 7 = 19`；
- 两项都勾选时，所有题目中混合分布两种形式；
- 填写算数模式下，答案页展示完整算式（如 `12 + 7 = 19`），便于核对。

### MW-02 数值范围与年级预设（P0）

- **配置方式明确分为两种**：
  - **年级预设**：选择年级预设，只影响内容规则（运算、范围、进退位、题量），界面展示当前预设的内容规则摘要；
  - **自定义规则**：独立配置运算、范围、进退位、题量；从预设进入自定义时保留当前值作为起点；
- 预设只影响内容规则；版式（列数、字号）与输出（答案页、姓名/日期、标题）在两种模式下都可独立调整；
- 年级预设如下（一键套用）：

| 预设 | 对应年级（参考人教版） | 范围 | 运算 | 默认题量 |
| --- | --- | --- | --- | --- |
| 10 以内加减 | 一年级上 | 0–10 | + − | 20 |
| 20 以内加减 | 一年级上/下 | 0–20 | + − | 20 |
| 100 以内加减 | 二年级上 | 0–100 | + − | 20 |
| 表内乘法 | 二年级上 | 1–9 因数 | × | 20 |
| 表内除法 | 二年级下 | 1–9 因数 | ÷ | 20 |
| 100 以内四则 | 二年级下–三年级 | 0–100 | + − × ÷ 混合 | 30 |
| 多位数乘一位数 | 三年级上 | 两位数 × 一位数 | × | P1 |
| 两位数乘两位数 | 三年级下 | 两位 × 两位 | × | P1 |
| 三位数乘两位数 | 四年级上 | 三位 × 两位 | × | P1 |
| 除数是一位数除法 | 三年级下 | 被除数 ≤ 三位数 | ÷ | P1 |

- 预设与「教材进度」对齐标注「参考人教版」，不承诺精确到单元。

**验收**：预设模式与自定义模式界面明确区分；选择预设后内容规则正确联动；切换到自定义时保留当前值；修改规则后不会被误认为仍是预设。

### MW-03 进退位控制（P0，加/减法）

- 两个独立勾选框：**进位加法**、**退位减法**；
- 勾选后对应题型必须进位/退位；未勾选则对应题型不进位/不退位；
- **两项都勾选时，加法进位与减法退位同时支持**，混合出现；
- 仅对加、减法生效；乘除不受影响；
- 默认两项都勾选。

**验收**：只勾「进位加法」时，加法题全部进位、减法题全部不退位；只勾「退位减法」时，减法题全部退位、加法题全部不进位；两项都勾选时，两种题型都出现。

### MW-04 题量（P0）

- 选项：10 / 20 / 30 / 40 / 50 / 自定义（1–100）；
- 默认 20；
- 题量与列数、字号联动校验（见 MW-05），题量过大时提示「建议分页」。

### MW-05 排版（P0）

- 列数：2 / 3 / 4 / 5，默认 4；
- 字号：小（10pt）/ 中（12pt）/ 大（14pt）/ 特大（16pt），默认中；题量较大时会自动降字号，保证一页放下；
- 填写算数模式下，列数上限为 4，以保证书写空间；等号与答案位置仍按列对齐；
- 行距：默认 10 mm；题量增大时自动压缩为 6 / 3 / 2 / 1.5 mm；
- 每道题使用固定列网格：**题号（4mm）| 算式（弹性、右对齐）| 等号（3mm）| 答案横线（固定宽度）**；
- 同一列内，所有**等号与答案横线上下对齐**；算式右对齐，短算式自然留出左侧空白；
- 答案横线宽度：2–3 列 20mm、4 列 14mm、5 列 11mm；填写算数模式下题内缺数横线 8mm；
- 版式示意：

```
1)  23 + 45 = ____________    2)  67 − 19 = ____________
3)   8 × 7 = ____________     4)  56 ÷ 8 = ____________
```

**验收**：20 题 4 列在 A4 标准边距下完整放入一页；无题目跨行/跨页；同一列内等号与答案横线对齐；算式不溢出/不重叠；字号特大时自动调整字号或列数。

### MW-06 答案页（P0）

- 开关「附带答案页」，默认关；
- 答案页**独立成页**，标题「答案」，字号 10–12 pt，紧凑多列（4–6 列）；填写算数模式下展示完整算式（4 列）；
- 答案与题目编号严格对应；
- 提供「仅打印练习页」的操作提示（打印范围选第 1 页）；
- 答案页不参与题目随机（同一套题固定答案）。

**验收**：默认生成 1 页题目、不附答案页；开启后生成 1 页题 + 1 页答案，答案与题目 100% 对应（自动校验）。

### MW-07 去重与避免无效题（P0）

- **页内不重复**：相同「运算 + 操作数」不出现两次；
- **避免无效题**：默认排除 `a + 0`、`a − 0`、`a × 1`、`a ÷ 1`、`0 × a`、`0 ÷ a`；
- **减法不出负数**；**除法必须整除**（含余数模式 P2 再议）；
- 结果与操作数均在设定范围内；
- 连续生成时尽量不与上一页完全重复（同参数换种子即可）。

**验收**：自动校验 1000 页生成结果：0 重复、0 负数、0 非整除、0 越界、0 无效题。

### MW-08 随机种子（P0）

- 同参数 + 同种子 → 同一套题（顺序也一致）；
- 「重新生成」换种子；种子可复制、可填入、可从 URL 恢复；
- 改变题量/列数等排版参数不改变题目（种子不变时，题目序列按前 N 题截取或补足——规则需固定：**先生成 100 题池，按题量截取**，保证改题量时前缀稳定）。

### MW-09 页眉信息栏（P0）

- 标题（默认「口算练习」，可改）；
- 姓名、班级（可选）、**日期（留空，由用户手写填写，不默认填当日）**、用时、正确率；
- 排版紧凑，位于内容区顶部，不占用题目空间过多（≤ 15 mm 高）。

**验收**：页眉内容完整、不换行溢出；日期栏为空白横线，不预填日期。

### MW-10 竖式排版（P1）

- 支持加减乘除竖式，每题固定宽度（≥ 35 mm）、对齐数位；
- 每页题量自动减少（建议 ≤ 12 题/页）；
- 乘除法竖式留出计算过程空间。

### MW-11 比大小（P1）

- 形式：`3 + 5 ○ 9`，填写 `>`、`<`、`=`；
- 左右两侧均为算式（不是纯数字），避免过于简单。

### MW-12 填空题（P1）

- 形式：`3 + ○ = 8`、`○ × 4 = 12`、`15 − ○ = 7`；
- 空缺位置随机（左操作数/右操作数/运算符），保证唯一解。

### MW-13 混合运算与括号（P1/P2）

- P1：两项混合（如 `3 + 4 × 5`），保证中间结果非负、结果在范围内；
- P2：带括号的两步运算、三步混合；
- 运算优先级必须正确，答案由表达式求值器计算（不手工拼接）。

### MW-14 批量生成（P0）

- 「多页不同」：N 页同参数不同种子（N ≤ 30）；
- 「多份相同」：同一页打印 N 份；
- 分页正确，答案页按「每页题 + 每页答案」或「全部题 + 全部答案」排列（需确认，建议后者便于批改）。

### MW-15 错题重练（P2）

- 用户可标记错题，生成同类型新题（本地记录，不上传）；
- 依赖本地存储，需明确隐私说明。

### MW-16 打印适配与省墨（P0）

- 纯黑白，无底纹；
- 题目区不出现装饰性边框（或可选细边框）；
- 答案页、练习页均遵循[打印规范](../03-print-spec.md)；
- 支持页边距切换后重新排版不溢出。

### MW-17 中英文文案（P0）

- 标题默认「口算练习 / Math Practice」，页眉字段「姓名 / Name、班级 / Class、日期 / Date、用时 / Time、正确率 / Score」与答案页标题「答案 / Answers」随界面语言切换；
- 运算符号、数字与算式本身语言无关；日期按语言格式化（中文「2026年11月9日」，英文「Nov 9, 2026」）；
- 英文标签更长，页眉需自适应，不得侵占题目区；必要时自动缩小 1 档字号；
- 切换语言不改变题目、答案与种子。

## 5. 题目生成规则

> 生成引擎必须把下列规则实现为**可测试的约束**，任一题不满足即重试或丢弃。答案由表达式求值器计算，禁止硬编码。

| 规则 | 说明 |
| --- | --- |
| R1 范围 | 操作数与结果均在用户设定范围内（默认「结果范围」= 操作数范围） |
| R2 非负 | 减法结果 ≥ 0；混合运算中间结果 ≥ 0 |
| R3 整除 | 除法必须整除；被除数 = 除数 × 商；除数 ≠ 0 |
| R4 进位/退位 | 按 MW-03 选项过滤 |
| R5 去重 | 同页「规范化表达式」不重复（交换律视为同一题：3+5 与 5+3 算重复） |
| R6 无效题 | 排除 0 与 1 的平凡运算（可配置） |
| R7 唯一解 | 填空题在设定范围内有且仅有一个解 |
| R8 位数 | 多位数题的操作数位数符合预设（如三位数乘两位数） |
| R9 混合优先级 | 先乘除后加减；括号优先 |
| R10 确定性 | 同种子 + 同参数 → 同题序；题量变化时前缀稳定 |

### 5.1 题量 → 排版建议

| 题量 | 列数 | 字号 | 行数/页 | 备注 |
| --- | --- | --- | --- | --- |
| 10 | 2–3 | 大/特大 | 5 | 低年级 |
| 20 | 4 | 中 | 5 | 默认，一页 |
| 30 | 4 | 中 | 8 | 一页偏满 |
| 40 | 4–5 | 小/中 | 8–10 | 建议分页或小字号 |
| 50 | 5 | 小 | 10 | 一页极限，需校验 |
| 60–100 | 5 | 小 | 12–20 | 自动分页（P1） |

> 最终以实际渲染测量为准：任何配置下不得出现题目溢出、挤压或跨页断裂。

## 6. 答案页规范

```
┌────────────────────────── 答案 ──────────────────────────┐
│ 1) 68   2) 48   3) 56   4) 7   5) 91   6) 27   ...      │
│ ...（4–6 列紧凑排列，字号 10–12pt）                       │
└───────────────────────────────────────────────────────────┘
```

- 编号与题目一一对应；
- 除法答案写商（P2 有余数时写「商……余数」）；
- 答案页可单独打印（打印范围提示）；
- 答案页不计入分页页码或标「答案」页。

## 7. 交互流程

1. 进入口算页 → 默认「100 以内加减 · 20 题 · 4 列 · 含答案」；
2. 选年级预设或手动调范围/运算/进退位；
3. 调题量、列数、字号 → 预览即时更新，溢出时提示；
4. 点「重新生成」换题；可复制种子/分享链接；
5. 「打印 A4」→ 逐页检查预览（题 + 答案）；
6. 需要 PDF → 打印对话框另存。

## 8. 边界与异常

| 情况 | 处理 |
| --- | --- |
| 范围内无法生成足够题目 | 提示「当前范围题目不足，建议扩大范围或减少题量」 |
| 题量/字号导致溢出 | 自动降列数/字号并提示；仍溢出则建议分页 |
| 混合运算生成失败（约束冲突） | 重试 ≤ 50 次，仍失败则降低运算种类并提示 |
| 年份/日期错误 | 使用本地时区当日；允许手动改 |
| 用户改题量后期望题目不变 | 按「100 题池截取」规则保持前缀稳定（见 MW-08） |

## 10. 非目标

- 在线答题、自动批改、成绩记录（无账号）；
- 题库版权内容（不复制教材原题）；
- 复杂应用题自动生成（P2 仅模板化，且需人工审核文案）；
- 服务端组卷/班级分发。
