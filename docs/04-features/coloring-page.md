# 04a · 功能规格：涂色页生成器

> 版本：v0.2 · 状态：草案 · 日期：2026-11-09
> 关联：[PRD](../02-prd.md) · [打印规范](../03-print-spec.md) · [技术方案](../05-architecture.md)

## 1. 目标与价值

为亲子活动、幼儿园/低年级美术课提供**线条闭合、区域大小合适、不费墨**的 A4 线稿，并且可以按孩子年龄调整复杂度与线条粗细。内容全部由程序生成，不依赖第三方素材，规避版权风险。

**成功标准**：家长选默认参数打印，孩子能独立涂完，不需要额外解释；线稿在 300 元级家用喷墨打印机黑白模式下不断线。

## 4. 功能需求

### CP-01 主题模板（P0）

提供三类可程序化生成的线稿，避免依赖美术素材：

| 主题 | 视觉特征 | 适合年龄 | 生成方式 |
| --- | --- | --- | --- |
| **对称花纹** | 中心对称/轴对称的装饰图案 | 3–8 岁 | 极坐标或镜像拼贴基本图形 |
| **曼陀罗** | 多层同心圆环，每环重复元素 | 5 岁+ | 极坐标分层，环数/瓣数随复杂度变化 |
| **几何图样** | 三角形/六边形/曲线拼贴 | 4 岁+ | 网格细分 + 随机线条 |

- 主题以卡片形式展示缩略图，点击即生成；
- 每个主题提供 3 个默认预设（幼儿/标准/进阶）。

**验收**：三类主题各有 ≥ 3 个预设；选择后 1s 内出现预览。

### CP-02 复杂度分级（P0）

- 1–5 级，映射到「封闭区域数量 + 最小区域面积 + 线密度」；
- 默认 3 级；
- 参数说明需展示效果差异（如「1 级 ≈ 8–12 个可涂区域；5 级 ≈ 60+ 区域」）；
- 复杂度提升不得导致区域小到无法涂色（低于最小面积阈值时自动合并/减少线条）。

**验收**：每级生成 10 次，区域数落在映射区间内；不存在面积 < 5 mm² 的区域（幼儿预设 < 20 mm² 不出现）。

### CP-03 线条粗细（P0）

三档：细（0.3 mm）/ 中（0.5 mm）/ 粗（1.0 mm），默认「中」。

- 粗线条面向幼儿与喷墨打印；
- 线条纯黑（`#000`），不描灰边；
- 线条粗细不影响图案区域数量（只改描边宽度）。

**验收**：打印样张中，粗线档在喷墨打印机上连续不断线。

### CP-04 版式（P0）

- A4 纵向，线稿居中，占可打印区域 85%–90%，四周留白均匀；
- 标题（可选）位于页眉，姓名栏可选；
- 线稿边界距纸边 ≥ 15 mm（含标准边距 15 mm 时即内容区边界）；
- 不出现跨页、不出现贴边裁切。

### CP-05 随机与复现（P0）

- 每次生成产生新种子；种子显示在操作区，可复制；
- 同一「主题 + 复杂度 + 线宽 + 种子」→ 完全相同的图案；
- 「重新生成」换种子；「锁定」后改排版参数不改变图案；
- 分享链接携带种子。

### CP-06 预览与打印（P0）

- 预览按 mm 等比缩放，显示纸张边界与页边距参考线（可开关）；
- 「打印 A4」隐藏界面元素，仅打印纸张；
- 提供打印指南入口（缩放 100%、选 A4、关页眉页脚）。

### CP-07 标题 / 姓名栏（P0）

- 标题默认「我的涂色页」（可自定义，≤ 30 字）；
- 姓名栏：「姓名：______」；日期栏可选；
- 字体使用开源无衬线字体，字号 10–11 pt。

### CP-08 批量生成（P1）

- 「生成 N 页不同图案」：同主题/复杂度/线宽，不同种子，每页独立；
- 「打印 N 份相同」：同一图案重复 N 次；
- N 上限 30；分页正确，无空白页。

### CP-09 省墨模式（P1）

- 去掉外边框与装饰线，仅保留线稿与标题；
- 不改变线稿本身（线稿已最省墨）。

### CP-10 编号涂色 by-numbers（P1）

- 将封闭区域映射到 6–8 种颜色编号（1–8），区域中央标注数字；
- 提供「颜色图例」：编号 + 颜色名（不打印大面积色块，避免费墨）；
- 数字字号 ≥ 8 pt，区域过小时不编号或合并；
- 提供「纯线稿 / 带编号」切换。

**验收**：图例编号与区域编号一一对应；无区域遗漏；小区域不出现不可读数字。

### CP-11 颜色图例（P1）

- 以文字 + 小色块（≤ 4×4 mm）展示；
- 黑白打印时仅显示编号与颜色名（省墨）。

### CP-12 素材与版权策略（P0）

- 只用程序生成图形，或使用明确可商用（MIT/CC0/OFL）的字体与图标；
- 不使用受商标/形象权保护的卡通角色；
- 页面底部可选择性展示「由 paper-maker 生成 · 可自由使用」；
- 生成物声明：用户可自由使用（含商用），无需署名（详见项目 README/LICENSE 与「关于」页）。

### CP-13 中英文文案（P0）

- 标题默认值中英文分别为「我的涂色页」/「My Coloring Page」，支持自定义；
- 姓名、日期、页脚等印刷文字随界面语言切换；
- 线稿本身无文字，切换语言不影响图案与种子；
- 英文标题更长，页眉必须允许换行或省略而不遮挡画布。

## 6. 生成策略（技术无关）

> 本节描述「生成什么、约束是什么」，不规定具体算法实现。

### 6.1 对称花纹

- 以中心点为原点，选择 1/2/4/6/8 重旋转对称或镜像对称；
- 在基本扇区/象限内随机放置 3–10 个基本图形（圆、花瓣、折线、弧）；
- 通过镜像/旋转复制生成完整图案；
- 复杂度控制：基本图形数量、层数、细分次数。

### 6.2 曼陀罗

- 由外向内 2–8 层同心环；
- 每层按 n 等分（n 随复杂度 6–24 变化），每份放置重复元素（水滴、三角、点、弧线）；
- 中心留白或放置小圆；
- 线条风格统一（同一线宽）。

### 6.3 几何图样

- 在画布上建立三角/六边形网格；
- 随机选择若干网格单元描边，或连接相邻顶点形成封闭多边形；
- 通过「随机游走 + 闭合」保证每条线都构成封闭区域；
- 复杂度控制：网格密度与描边比例。

### 6.4 硬性约束

| 约束 | 阈值 |
| --- | --- |
| 所有线稿必须闭合（可涂色） | 每条边属于 ≥ 1 个封闭区域 |
| 最小封闭区域面积 | ≥ 5 mm²（幼儿预设 ≥ 20 mm²） |
| 最大区域数量 | ≤ 120（避免线条过密） |
| 线宽 | 0.3–1.0 mm，按档位固定 |
| 留白 | 图案外接框距纸边 ≥ 15 mm |
| 生成失败重试 | ≤ 3 次，仍失败则降级复杂度并提示 |

### 6.5 复杂度映射（建议值，待样张校准）

| 级别 | 区域数 | 线条层数 | 最小区域 | 适合 |
| --- | --- | --- | --- | --- |
| 1 | 8–15 | 1–2 | ≥ 20 mm² | 3–4 岁 |
| 2 | 15–25 | 2–3 | ≥ 12 mm² | 4–5 岁 |
| 3 | 25–40 | 3–4 | ≥ 8 mm² | 5–7 岁 |
| 4 | 40–70 | 4–6 | ≥ 6 mm² | 7–10 岁 |
| 5 | 70–120 | 5–8 | ≥ 5 mm² | 成人 |

## 8. 交互流程

1. 从主页面点击「涂色页」→ 打开工具页，自动生成默认图案；
2. 选主题卡片 → 预览更新；
3. 调复杂度/线宽 → 预览更新（≤ 150ms）；
4. 需要不同图案 → 点「重新生成」（换种子）；
5. 满意 → 点「打印 A4」→ 浏览器打印对话框；
6. 想保存 → 打印对话框选「另存为 PDF」；
7. 想复现 → 复制种子/分享链接。

## 9. 边界与异常

| 情况 | 处理 |
| --- | --- |
| 复杂度 5 + 粗线条导致线条粘连 | 自动降低区域数或提示「粗线条建议复杂度 ≤ 4」 |
| 生成超时（> 1s） | 降级复杂度重试，提示「已自动简化」 |
| 区域过小无法涂色 | 合并区域，保证最小面积 |
| 标题过长 | 输入限制 30 字，超出截断并提示 |
| 喷墨打印线条断裂 | 打印指南建议选粗线档、清洁喷头 |
| 打印被裁切 | 引导打印校准页，检查 A4/缩放设置 |
