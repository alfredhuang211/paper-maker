# 04e · 功能规格：数独生成器

> 版本：v0.1 · 状态：草案 · 日期：2026-11-11
> 关联：[PRD](../02-prd.md) · [打印规范](../03-print-spec.md) · [设计系统](../07-design-system.md)

## 1. 目标

生成可直接打印、可直接用笔填写的数独页。支持标准 9×9 与更小的 4×4 / 6×6，适合从幼儿到成人的不同难度，并支持一页多题。

## 2. 用户故事

| # | 故事 |
| --- | --- |
| SD-US1 | 家长打印一张 4×4 数独给幼儿入门。 |
| SD-US2 | 老师一次打印 4 道 6×6 数独，分给小组。 |
| SD-US3 | 成人打印标准 9×9 困难数独。 |
| SD-US4 | 想复现同一套题，用种子重新生成。 |

## 3. 范围

| 优先级 | 内容 |
| --- | --- |
| **P0** | 4×4 / 6×6 / 9×9；简单/中等/困难；每页 1/2/4 题；A4 打印；种子；批量；中英文 |
| **P1** | 答案页；按种子固定题面；难度按解题技巧分级 |
| **P2** | 12×12/异形数独；一页 6 题 |

## 4. 功能需求

### SD-01 规格（P0）

| 规格 | 宫格 | 数字 | 说明 |
| --- | --- | --- | --- |
| 4×4 | 2×2 | 1–4 | 入门 |
| 6×6 | 2×3 | 1–6 | 进阶 |
| 9×9 | 3×3 | 1–9 | 标准 |

### SD-02 难度（P0）

- 简单 / 中等 / 困难，按移除格子数量控制；
- 每题必须保证**唯一解**；
- 4×4 保留 7–11 个提示数；6×6 保留 16–24 个；9×9 保留 33–51 个。

### SD-03 每页多题（P0）

- 每页可选 1 / 2 / 4 题；
- 1 题：大图居中；
- 2 题：上下排列；
- 4 题：2×2 排列；
- 每页标题、姓名/日期；多题时每题显示「第 N 题」；
- 单格尺寸按页面自动计算，粗线宫边界清晰。

### SD-04 随机与复现（P0）

- 同一规格 + 难度 + 种子 → 同一题面与解；
- 「重新生成」换种子；批量生成使用派生种子；
- 种子显示在页脚，可复制/从 URL 恢复。

### SD-05 打印（P0）

- A4 纵向；一页一页输出；
- 粗线（0.5mm）宫边界 + 细线（0.25mm）格线；
- 打印/下载 PDF 输出全部页面。

### SD-06 中英文（P0）

- 规格、难度、按钮、页眉、说明均随界面语言切换；
- 数独本身无文字。

## 5. 生成策略

1. 用随机回溯生成完整解（4×4 宫 2×2；6×6 宫 2×3；9×9 宫 3×3）；
2. 打乱格子顺序，逐个尝试清空；
3. 每次清空后用回溯求解器计数，最多数到 2；只有唯一解才保留清空；
4. 达到难度对应的移除数量或无法继续为止。

## 6. 验收标准

| # | 场景 | 期望 |
| --- | --- | --- |
| SD-AC1 | 4/6/9 各生成并打印 | 1 页 A4；题面完整；格线与宫线清晰 |
| SD-AC2 | 简单/中等/困难 | 提示数在对应区间；每题唯一解 |
| SD-AC3 | 每页 1/2/4 题 | 对应数量；排列正确；不超出纸张 |
| SD-AC4 | 同种子两次 | 题面与解一致 |
| SD-AC5 | 批量 2 张 | 2 页，题面不同 |
| SD-AC6 | 手机端 | 可调参、预览；无横向滚动 |

## 7. 非目标

- 首版不做解题器/答案页（P1）；
- 不做在线答题、计时、排行。
