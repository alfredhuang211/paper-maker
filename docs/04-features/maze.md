# 04d · 功能规格：迷宫生成器

> 版本：v0.1 · 状态：草案 · 日期：2026-11-11
> 关联：[PRD](../02-prd.md) · [打印规范](../03-print-spec.md) · [设计系统](../07-design-system.md)

## 1. 目标

生成一张**单页 A4、可直接用笔走**的连通迷宫，用于儿童专注力/路径规划练习、课堂热身或亲子活动。迷宫由程序生成，不依赖第三方素材。

**成功标准**：默认参数下打开即可打印；入口/出口清晰；路径连通、无孤岛；线宽足够家用打印机识别。

## 3. 范围

| 优先级 | 内容 |
| --- | --- |
| **P0** | 10×10 / 15×15 / 20×20 / 30×30；细/中/粗线条；A4 预览/打印；种子；标题/姓名/日期；批量多张；中英文 |
| **P1** | 解法页（答案页）；矩形/异形迷宫；入口/出口位置可选；难度分级（基于死路比例） |
| **P2** | 迷宫主题（动物/字母路径）；多迷宫同页 |

## 4. 功能需求

### MZ-01 迷宫规格（P0）

- 尺寸：10×10 / 15×15 / 20×20 / 30×30，默认 15×15；
- 单格尺寸随页面可用区域自动计算；10×10 约 18mm/格，30×30 约 6mm/格；
- 所有格子必须连通；入口位于左上角，出口位于右下角（外墙留缺口）。

### MZ-02 线条（P0）

- 细 0.35mm / 中 0.5mm / 粗 0.7mm，默认中；
- 纯黑、无填充；粗线条适合幼儿与喷墨打印。

### MZ-03 版式（P0）

- A4 纵向，内容区 180×267mm；
- 页眉：标题（默认「迷宫」）、姓名/日期（可关）；
- 迷宫居中，占内容区最大 180×230mm；
- 页脚：使用说明 + 种子；底部可显示「从左上角进入，沿通道走到右下角出口」。

### MZ-04 随机与复现（P0）

- 同尺寸 + 同线宽 + 同种子 → 完全相同迷宫；
- 「重新生成」换种子；种子可复制、可从 URL 恢复；
- 批量生成使用派生种子，每张不同。

### MZ-05 多张与打印（P0）

- 复用通用「生成张数」1/2/3/5/10 与「每张不同/相同」；
- 打印/下载 PDF 输出全部页面，每张 A4 一页。

### MZ-06 中英文（P0）

- 标题、姓名/日期、说明、按钮均随界面语言切换；
- 迷宫本身无文字，语言切换不影响布局与种子。

## 5. 生成策略

- 使用递归回溯（DFS）在 `n×n` 网格上生成完美迷宫（任意两点间唯一路径）；
- 从左上角开始，随机选择未访问邻居、打通墙、回溯，直到所有格子访问完毕；
- 打开左上格外墙为入口、右下格外墙为出口；
- 输出墙段集合（网格坐标），渲染为 SVG 线段；线宽按 mm 换算到 viewBox 单位，保证打印实际线宽。

## 6. 验收标准

| # | 场景 | 期望 |
| --- | --- | --- |
| MZ-AC1 | 默认 15×15 打印 | 1 页 A4；迷宫完整；入口/出口开口；线宽符合设置 |
| MZ-AC2 | 10/15/20/30 各生成 20 次 | 所有格子连通；无越界墙段 |
| MZ-AC3 | 同种子两次 | 墙段完全一致 |

| MZ-AC6 | 打印验收清单 | 通过（见打印规范 §10） |

## 7. 非目标

- 不做 3D 迷宫、动态迷宫；
- 首版不做解法页（P1）；
- 不承诺难度分级与年龄的严格对应。
