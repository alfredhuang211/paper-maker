# 04f · 功能规格：涂色画生成器

> 版本：v0.1 · 状态：草案 · 日期：2026-11-11
> 关联：[PRD](../02-prd.md) · [打印规范](../03-print-spec.md) · [设计系统](../07-design-system.md)

## 1. 目标

从**公共领域 / 开源可自由使用**的图像生成黑白线条框，输出可直接打印涂色的 A4 页面。与「涂色页」的程序化线稿互补：一个提供抽象图案，一个提供具象图片。

**成功标准**：默认图片打开即有一张清晰的 A4 线稿；线条闭合可涂色；打印不糊；图片来源与许可清晰可见。

## 4. 功能需求

### CPIC-01 图片库（P0）

- 内置 17 张全页场景图片：海底世界、海底世界 2、水族馆、热带海滩、小城街景、野餐时光、太空探险、动物乐园、非洲草原、自然风光、雪地玩耍、农场拖拉机、滑稽散步、鱼缸世界、动物涂色页、海龟与海浪、水母；
- 其中 14 张来自 Openclipart（Public Domain/CC0），3 张来自 Pixabay/Unsplash/Pexels（各自免费许可，非 CC0）；
- 优先选择全画幅、线条清晰、构图简单、少交叉线的场景图；
- 图库混合许可，因此不统一宣称 CC0；页面按图片显示对应许可；
- 图库以**处理后的线稿缩略图**展示，与 A4 页面效果一致；选中状态高亮；
- 线条粗细变化时，缩略图与页面同步更新；
- 图片与许可来源记录在 `public/coloring-images/ATTRIBUTION.md`。

### CPIC-02 用户图片（P0）

- **本地上传**：支持 PNG / JPEG / WebP / SVG 等浏览器可解码图片；使用 `URL.createObjectURL`，不上传服务器；
- **图片 URL**：通过 `fetch`（CORS）加载；仅支持 http/https；
- URL 图片需目标服务器允许跨域；不允许时给出明确提示，建议下载后上传；
- 用户图片默认标题取文件名/URL 文件名，可编辑；
- 用户图片许可显示「用户提供 · 请确认版权」，不默认可自由使用；
- CORS 失败、网络超时（15s）、非图片内容均显示错误提示，不阻塞其他功能。

### CPIC-03 线稿化（P0）

- **SVG 图片**：读取 SVG 文本，注入「只描边、不填充」样式，再栅格化；保留原始线条并补出填充图形的轮廓，得到干净的线框图；
- **位图图片**：自动判断是线稿还是照片/彩色插画；线稿走灰度阈值，彩色/照片走 Sobel 边缘提取，避免整块填黑；
- 线条粗细三档：细 / 中 / 粗；SVG 对应描边宽度，位图对应阈值与膨胀/边缘参数；
- 以最长边 1400px 渲染；自动裁掉四周白边，让主体填充约 97%–99% 的画面；
- 不修改原图；不上传；
- 输出为 PNG 数据 URL，嵌入 A4 纸张预览；
- 图库缩略图也走同一转换流程，保证「选中图 = 实际页面」。

### CPIC-04 版式（P0）

- A4 纵向，内容区 180×267mm；
- 页眉：标题（默认为图片名，可改）、姓名/日期（可关）；
- 线稿按比例居中，最大 180×230mm；
- 页脚：图片标题 + 对应来源许可 + paper-maker；
- 线条保留足够留白，便于涂色。

### CPIC-05 打印（P0）

- 打印/下载 PDF 输出当前页面；
- 屏幕 UI 不进入打印内容；
- 线条在黑白打印下清晰可辨。

### CPIC-06 许可与来源（P0）

- 工具页显示当前图片的源站链接（Openclipart / Pixabay / Unsplash / Pexels）；
- 纸张页脚标注对应许可（如 `Public Domain (Openclipart)`、`Pixabay Content License`）；
- 仅打包处理后的线稿；不打包外部源站原图，避免原样再分发；
- 不声称对原图片拥有版权；生成物按对应来源许可使用，不统一再授权为 CC0。

### CPIC-07 中英文（P0）

- 图片标题、UI 文案随语言切换；
- 打印内容语言跟随界面。

## 5. 转换流程

1. SVG：读取文本，注入「只描边、不填充」样式，白底栅格化；
2. 位图：先判断线稿/彩色，线稿走阈值，彩色/照片走 Sobel 边缘；
3. 按最长边 1400px 等比缩放，居中绘制；
4. 自动裁掉白边，输出黑线白底 PNG，作为 A4 页面内容；
5. 图库缩略图复用同一流程，保证与实际页面一致。

## 6. 验收标准

| # | 场景 | 期望 |
| --- | --- | --- |
| CPIC-AC1 | 17 张图片逐张选择 | 每张都能成功处理，线稿非空且可辨认 |
| CPIC-AC2 | 细/中/粗 | 线条粗细可见差异；默认中等 |
| CPIC-AC3 | A4 打印/PDF | 1 页 A4；线稿不裁切；来源信息可见 |
| CPIC-AC4 | 许可 | 页面与文档按图片显示对应来源与许可，不把非 CC0 图片误标为 CC0 |
| CPIC-AC5 | 手机端 | 可选图、选线条、预览；无横向滚动 |
| CPIC-AC6 | 中英文 | 图片名与 UI 同步切换 |
| CPIC-AC7 | 上传本地图片 | 可读取并转换为线稿；不上传；标题默认为文件名 |
| CPIC-AC8 | 图片 URL | 同源/允许 CORS 的图片可转换；无 CORS 或超时给出提示 |

## 7. 非目标

- 不提供服务器端图片代理；外部图片需允许 CORS；
- 不做彩色参考图；
- 不抓取未授权图片；用户需自行确认图片版权。
