# 04f · 功能规格：涂色画生成器

> 版本：v0.1 · 状态：草案 · 日期：2026-11-11
> 关联：[PRD](../02-prd.md) · [打印规范](../03-print-spec.md) · [设计系统](../07-design-system.md)

## 1. 目标

从**公共领域 / 开源可自由使用**的图像生成黑白线条框，输出可直接打印涂色的 A4 页面。与「涂色页」的程序化线稿互补：一个提供抽象图案，一个提供具象图片。

**成功标准**：默认图片打开即有一张清晰的 A4 线稿；线条闭合可涂色；打印不糊；图片来源与许可清晰可见。

## 3. 范围

| 优先级 | 内容 |
| --- | --- |
| **P0** | 8 张 Openclipart Public Domain 图片；浏览器本地线稿化；细/中/粗线条；A4 预览/打印/PDF；标题/姓名/日期；中英文；来源许可展示 |
| **P1** | 更多图片；线稿阈值/细节调节；答案式彩色参考图；多张同页 |
| **P2** | 用户上传本地照片（仅在本地处理，不上传）；AI 插画 |

## 4. 功能需求

### CPIC-01 图片库（P0）

- 内置 8 张图片：蝴蝶、花朵、恐龙、火箭、小鱼、猫咪、猫头鹰、独角兽；
- 全部来自 Openclipart，Public Domain / CC0，可自由使用；
- 图库以缩略图网格展示；选中状态高亮；
- 图片与许可来源记录在 `public/coloring-images/ATTRIBUTION.md`。

### CPIC-02 线稿化（P0）

- 在浏览器内用 `<canvas>` 读取图片；
- 以最长边 1400px 渲染；灰度 + 阈值 + 形态学膨胀生成黑白线条；
- 线条粗细三档：细 / 中 / 粗（对应阈值与膨胀半径不同）；
- 不修改原图；不上传。
- 输出为 PNG 数据 URL，嵌入 A4 纸张预览。

### CPIC-03 版式（P0）

- A4 纵向，内容区 180×267mm；
- 页眉：标题（默认为图片名，可改）、姓名/日期（可关）；
- 线稿按比例居中，最大 180×230mm；
- 页脚：图片来源 + Public Domain + paper-maker；
- 线条保留足够留白，便于涂色。

### CPIC-04 打印（P0）

- 打印/下载 PDF 输出当前页面；
- 屏幕 UI 不进入打印内容；
- 线条在黑白打印下清晰可辨。

### CPIC-05 许可与来源（P0）

- 工具页显示当前图片的 Openclipart 来源链接；
- 纸张页脚标注 `Openclipart · Public Domain`；
- 不声称对原图片拥有版权；生成物供用户自由使用。

### CPIC-06 中英文（P0）

- 图片标题、UI 文案随语言切换；
- 打印内容语言跟随界面。

## 5. 转换流程

1. `Image` 加载本地 SVG；
2. 白底 canvas，按最长边 1400px 等比放大/缩小，居中留 24px 边距；
3. 计算亮度，低于阈值记为黑；
4. 按线条粗细做 0 / 1 / 2 像素膨胀；
5. 输出黑线白底 PNG，作为 A4 页面内容。

## 7. 非目标

- 首版不支持用户上传照片（P2，且必须本地处理）；
- 不做彩色参考图；
- 不抓取未授权图片。
