## M1 · 工程骨架（预估 3–5 天）

**目标**：跑通「参数 → 生成 → A4 预览 → 打印 → 部署」全链路，用**一个最小工具**验证（建议先做舒尔特方格，逻辑最简单）。

**范围**

- Vite + TS + React 工程初始化；ESLint/Prettier/Vitest；
- 全局布局、路由、主页面子应用列表（注册表驱动）；
- 工具注册表、参数面板通用控件、A4 预览容器；
- i18n 骨架：中英文案表、浏览器语言检测（默认跟随浏览器）、右上角语言切换、`<html lang>` 同步；
- `@page` 打印样式、打印按钮、打印指南页、100mm 校准页；
- 种子 PRNG 与 URL 参数同步；
- 舒尔特方格最小版（5×5，数字，打印）；
- GitHub Actions：lint/test/build → Pages 部署；
- 线上冒烟测试（Playwright 打开主页面与工具页）。

**验收门槛**

- 线上 URL 可访问，资源无 404；
- 手机/桌面可完成一次生成与打印；
- 打印样张：A4 无裁切、格子尺寸正确、无空白页；
- 语言切换可用：默认跟随浏览器、右上角可切换、切换不丢参数（骨架页）；
- Lighthouse Perf/A11y ≥ 90；
- CI 全绿，部署自动完成。

**明确不做**：批量、答案页、PWA、复杂参数。

## M2 · 首批三件套（预估 2–3 周）

**目标**：三个工具的 P0 需求全部可用，达到「默认参数即可打印」的质量。

**范围**

| 工具 | P0 交付 |
| --- | --- |
| 涂色页 | 三类主题、复杂度 1–5、线宽 3 档、标题/姓名栏、种子、批量（1–10） |
| 口算页 | 加减乘除/混合、范围、进退位、题量 10–100、2–5 列、答案页、去重、页眉信息栏 |
| 舒尔特方格 | 3×3–7×7、记录栏、训练说明、批量、中心标记 |

> 三个工具的界面文案与打印文案（标题/页眉/答案页/训练说明）均需中英双语。

**跨工具**

- 批量生成框架（多页/多份）；
- 答案页通用能力；
- 参数预设与「最近使用」；
- 分享链接；
- 打印校验（溢出检测）与提示；
- 全部 P0 界面与打印文案中英双语，英文长文案版式溢出检查。

**验收门槛**

- 三工具 P0 验收标准（各功能规格 §10）全部通过；
- 打印验收清单在 Chromium + Safari 各打印一次通过；
- 中英文各打印一套样张通过（标题/页眉/答案页/训练说明无缺失、无溢出）；
- 生成引擎单测覆盖率 ≥ 90%，固定种子快照稳定；
- 目标：Lighthouse ≥ 90，首屏 JS ≤ 150KB。

**风险**：涂色页生成算法质量是最大不确定项，M1 期间可先做算法原型（不进入主线）。

## M3 · 体验完善（预估 1–2 周）

**目标**：从「能用」到「好用、可分享、可长期使用」。

**范围**

- 本地预设（命名、收藏、删除）；
- 批量「多版本」「合集 PDF」；
- PWA 离线与安装；
- 无障碍完善（键盘、对比度、屏幕阅读器）；
- 打印校准页交互化（输入测量值给出诊断）；
- 错题重练（口算，本地记录）；
- 涂色 by-numbers / 颜色图例（P1）；
- 口算竖式 / 填空 / 比大小（P1）；
- 舒尔特字母版 / 中文数字 / 同页多格（P1）；
- 页面 SEO/OG、Changelog、关于/隐私页。

**验收门槛**

- 断网后仍可生成与打印（首次访问后）；
- 移动端完整可用；
- 全部 P1 功能有验收记录；
- 无新增严重打印回归。

---

## M4 · 工具扩展（预估 2–4 周，按需）

**目标**：验证「工具注册表」的扩展性，补足高频品类。

**候选顺序**（按需求 × 实现成本）

1. 迷宫（复用网格与路径算法）
2. 描红/字帖（田字格，需字体子集）
3. 坐标纸/网格纸/五线谱（低成本）
4. 数独（难度分级成本高）
5. 连点成画
6. 单词默写/时钟练习

**验收门槛**

- 新工具复用通用能力 ≥ 80%；
- 文档、单测、打印验收齐备；
- 不显著增加首屏包体（按路由分割）。

---

## M5 · 打磨发布（预估 1 周）

**目标**：对外发布 v1.0。

**范围**

- 全量打印验收（多打印机、多浏览器）；
- 性能优化与包体审计；
- 无障碍审计；
- 文档与示例完善（每个工具 3 组推荐参数）；
- 发布说明、贡献指南、Issue 模板；
- 可选的匿名访问统计（需重新评估隐私影响）。

**验收门槛**

- 所有工具 P0/P1 通过验收；
- 打印验收清单在 ≥ 2 种浏览器 × 2 种打印机通过；
- 无 P0/P1 级缺陷；
- 文档可让新用户 60 秒内完成第一次打印。
