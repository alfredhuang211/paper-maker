# 03 · 打印与 A4 规范

> 版本：v0.3 · 状态：草案 · 日期：2026-11-09
> 本文是 paper-maker 所有工具的**打印验收依据**。凡涉及纸面尺寸、边距、线宽、字号、打印样式，一律以本文为准。

## 1. 目标

1. 用户在 A4 纸上打印出来的内容与屏幕预览**版式一致**，不裁切、不缩放、不多出空白页；
2. 内容在**家用喷墨/激光打印机、黑白模式**下清晰可读；
3. 对 Chrome / Edge / Safari / Firefox 的打印差异有明确预期与兜底方案。

---

## 2. A4 基础数据

| 项目 | 数值 |
| --- | --- |
| A4 尺寸 | **210 × 297 mm**（8.27 × 11.69 in） |
| 300 DPI 像素 | **2480 × 3508 px** |
| 96 DPI（CSS px） | **793.7 × 1122.5 px**（1 mm = 96 / 25.4 ≈ 3.7795 px） |
| 3 mm 出血版 | 216 × 303 mm（2551 × 3579 px @300DPI） |
| 常见不可打印边距 | 激光打印机约 4–5 mm；喷墨打印机下边距常达 10 mm 以上 |
| 建议安全边距 | 正文距纸边 ≥ 10 mm；页脚/装订侧 ≥ 15 mm |

> 参考：<https://polotno.com/tools/a4-size-in-pixels>、ISO 216 标准。

### 2.1 可打印区域

打印机的物理不可打印边距无法由网页控制，因此：

- 页面内容**必须**位于距纸边 ≥ 10 mm 的安全区内；
- 装饰性元素（边框、底纹）也不得贴边，避免被裁；
- 页脚文字距底边 ≥ 15 mm。

---

## 3. 页面设置

| 设置项 | 选项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 纸张 | A4（固定） | A4 | 不提供 Letter 等尺寸，避免误打印 |
| 方向 | 纵向 / 横向 | 纵向 | 首版工具均纵向；横向能力预留 |
| 页边距 | 窄 10mm / 标准 15mm / 宽 20mm / 自定义 | 标准 15mm | 实际内容区 = 210 − 2×边距 |
| 页眉 | 标题 / 姓名栏 / 日期栏（独立开关） | 标题开、姓名日期开（口算/舒尔特） | 涂色页默认只留标题/姓名 |
| 页脚 | 页码 / 说明文字 / 版权（可关） | 页码开 | 批量时页码必要 |
| 省墨模式 | 开 / 关 | 关 | 去底纹、去装饰边框、纯黑线条 |

> 例：标准边距 15 mm 时，内容区宽 **180 mm**，高 **267 mm**。

---

## 4. 单位与实现约束

1. **版式一律用 mm**，禁止用 px 定义纸张、边距、格子、线宽；px 仅用于屏幕 UI 与预览缩放。
2. 屏幕预览按比例缩放（如 75%），但内部布局坐标系始终是 210 × 297 mm。
3. 打印时使用独立样式表：

```css
@page {
  size: A4;
  margin: 0; /* 页边距由内部容器控制，避免浏览器与内容双重留白 */
}

@media print {
  .app-chrome { display: none !important; }   /* 隐藏导航、参数面板、按钮 */
  .sheet {
    width: 210mm;
    height: 297mm;
    margin: 0;
    box-shadow: none;
    break-inside: avoid;
    page-break-inside: avoid;
  }
  body {
    -webkit-print-color-adjust: exact;
    print-color-adjust: exact;
  }
  .answer-sheet { break-before: page; }        /* 答案页强制新页 */
}
```

4. 分页控制：
   - 批量多页：每张 `.sheet` 一页，`break-after: page`；
   - 题目/区块不允许被切成两半：`break-inside: avoid`；
   - 答案页：`break-before: page`。

5. 打印内容容器**固定 210×297mm**，内部按边距排布；不使用 `position: fixed`（打印时位置不可控）。

## 5. 线宽与字号

### 5.1 线宽

| 用途 | 建议线宽 | 说明 |
| --- | --- | --- |
| 涂色页（幼儿/低年级） | **0.5–1.0 mm**（约 1.4–2.8 pt） | 太细家用喷墨易断线；「粗线条」档建议 1.0 mm |
| 涂色页（成人/复杂） | 0.3–0.5 mm | 精细图案 |
| 表格/方格线 | 0.3–0.5 mm | 舒尔特网格 |
| 题目分隔线/装饰线 | 0.2–0.3 mm | 不承载信息，可省墨 |
| **绝对下限** | **0.25 mm** | 低于此值多数家用打印机会断线 |

### 5.2 字号

| 内容 | 建议字号 | 说明 |
| --- | --- | --- |
| 页面标题 | 16–20 pt | |
| 口算题目 | ≥ 14 pt | 低年级 18–20 pt；保证书写空间 |
| 舒尔特数字 | 自动（格子尺寸的 40–50%） | 5×5 时约 18–22 pt |
| 页眉姓名/日期 | 10–11 pt | |
| 页脚说明/版权 | 8–9 pt | 可关闭 |
| 答案页答案 | 10–12 pt | 紧凑排版 |

### 5.3 书写空间

- 口算：每道题横向留白 ≥ 25 mm（答案书写区），行高 ≥ 10 mm；
- 舒尔特：单格边长 ≥ 18 mm（5×5 推荐 35–40 mm）；
- 涂色：最小封闭区域面积 ≥ 5 mm²（幼儿版 ≥ 20 mm²），避免无法涂色。

### 5.4 多语言印刷文案

- 所有印刷文字（标题、姓名/日期/用时/正确率、答案页「答案 / Answers」、训练说明、页脚）随界面语言切换；
- 英文文案通常比中文长 30%–80%，页眉/页脚使用弹性布局，**禁止截断或挤压主体内容**；必要时自动缩小 1 档字号；
- 字体栈：中文用 Noto Sans SC（OFL），英文用 Inter / Noto Sans / system-ui；数字使用 tabular 数字，保证列对齐；
- 日期格式由 i18n 层统一：中文「2026年11月9日」，英文「Nov 9, 2026」；
- 打印验收时中英文各打印一套样张。

## 6. 打印样式要点

| 要点 | 做法 |
| --- | --- |
| 隐藏界面 | 打印样式隐藏导航、参数面板、按钮、提示、Toast |
| 屏幕风格隔离 | 屏幕端的颜色、圆角、阴影、留白不得进入打印内容；打印固定纯黑白线稿 |
| 背景色 | 打印内容本身以白底黑线为主；必须打印的色块加 `print-color-adjust: exact` |
| 黑白可辨识 | 不依赖颜色区分信息；灰度对比足够（如答案用加粗/括号而非浅灰） |
| 省墨 | 默认无大面积底纹；线稿纯黑（`#000`）；提供省墨开关 |
| 页眉页脚 | 由内容自身实现，提示用户**关闭浏览器自带的页眉页脚** |
| 缩放 | 提示用户选「实际大小 / 100%」，不要选「适应页面」；提供校准页验证 |
| 纸张尺寸 | 提示在打印对话框选择 A4；避免打印机默认 Letter |
| 双面 | 不假设双面打印；答案页默认新页起始 |

## 7. PDF 导出策略

| 方案 | 体积/成本 | 优点 | 缺点 | 采用 |
| --- | --- | --- | --- | --- |
| **浏览器打印 → 另存为 PDF** | 0 KB | 矢量、零依赖、版式与打印一致 | 受浏览器打印设置影响；页边距控制有限 | ✅ P0 主路径 |
| `pdf-lib` | 约 360 KB gzip（按需加载） | 可精确控制 mm 坐标、矢量嵌入、文件小 | 不渲染 HTML/CSS，需手工排版；工作量大 | ⏳ P2 评估 |
| `jsPDF` | 约 410 KB gzip | 纯前端绘图、mm 坐标 | 不渲染 HTML；配 html2canvas 会栅格化，文件大、文字不可选 | ❌ 不采用 |
| 服务端（Playwright/Chromium） | 需后端 | 版式完全可控、可批量 | 与「纯静态、零后端」定位冲突 | ❌ 不采用 |

**结论**：P0 用浏览器打印作为唯一导出路径，把 `@page` 与打印样式做到位；P2 再评估 `pdf-lib` 做「精确 A4 矢量导出」，用于对版式要求极高的场景。

## 8. 黑白与省墨

- 练习页天然以线稿为主，**默认就是省墨的**；
- 禁止：大面积灰色底、彩色标题、装饰性色块；
- 灰度层次用线宽与图案区分，而非浅灰填充；
- 省墨模式：去掉外边框、页脚装饰、背景纹理；
- 涂色页的 by-numbers（P1）需提供「纯数字 + 轮廓」版本，避免打印大色块图例。

## 9. 浏览器差异（待实测校准）

> 以下为已知经验，M1 建立实测矩阵后更新。测试环境：macOS / Windows 各一台，Chrome、Edge、Safari、Firefox 最新版，至少一台喷墨 + 一台激光。

| 浏览器 | `@page size/margin` | 背景色 | 已知问题 | 兜底 |
| --- | --- | --- | --- | --- |
| Chrome / Edge（Chromium） | 支持较好 | 需 `print-color-adjust: exact` | 默认页眉页脚（URL/日期） | 提示关闭页眉页脚 |
| Safari | `@page size` 支持弱 | 默认不打印背景色 | 边距行为与 Chromium 不同 | 固定内容容器尺寸；提供校准页 |
| Firefox | 部分支持 | 支持 | 打印缩放选项差异 | 提示 100% 缩放 |

**校准页**：提供一张 100 mm 标尺（带刻度与说明文字）。用户打印后用尺量：
- 量得 100 mm → 缩放正确；
- 量得约 97 mm（A4 被按 Letter 适配）→ 提示选择 A4；
- 量得其他值 → 提示关闭「适应页面」并重试。

## 10. 打印验收清单

每个工具、每个 P0 版式，在以下环境各打印一次（黑白优先）：

- [ ] A4 纵向，缩放 100%，关闭浏览器页眉页脚；
- [ ] 内容完整，无裁切、无内容贴边；
- [ ] 页边距与设置一致（误差 ≤ 1 mm，用尺量）；
- [ ] 无多余空白页；批量时分页正确；
- [ ] 线宽 ≥ 0.25 mm，无断线；幼儿版线条 ≥ 0.5 mm；
- [ ] 字号可读，书写空间足够；
- [ ] 答案页独立成页，标题标注「答案」；
- [ ] 黑白打印下所有信息可辨识；
- [ ] 100 mm 校准页量得 100 mm；
- [ ] 页眉/页脚/页码位置正确；
- [ ] 中英文两套样张均通过（英文文案不截断、不溢出、不挤压主体）；
- [ ] 喷墨与激光各至少一台通过。
