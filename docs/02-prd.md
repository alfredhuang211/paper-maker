## 1. 产品概述

### 1.1 一句话定位

**paper-maker 是一个免费的、无需注册的 A4 练习页生成器合集**：主页面列出全部生成子应用（每个子应用对应一种生成能力），选子应用 → 调参数 → 在页面上看到真实 A4 预览 → 打印或存成 PDF。应用支持中英文切换，入口在右上角，首次访问默认跟随浏览器语言。

首批提供三类工具：

- **涂色页**：程序化生成对称花纹、曼陀罗、几何线稿；
- **口算页**：按年级/数值范围/题型生成口算题，自动配答案页；
- **舒尔特方格**：3×3 ~ 7×7 数字方格，打印即用，附训练方法。

### 1.2 产品愿景

让「找一张合适的练习纸」从 **5 分钟的下下载载** 变成 **30 秒的打印**，并且这张纸**恰好适合眼前这个孩子**。

### 1.3 产品目标

| 维度 | 目标 |
| --- | --- |
| 用户价值 | 免费、无广告、无注册地获得可调、可打印、带答案的 A4 练习材料 |
| 体验目标 | 从打开页面到开始打印 ≤ 60 秒（默认参数直接可用） |
| 工程目标 | 纯静态、零后端、可离线；打印结果与预览一致 |
| 国际化 | 中英双语；界面与打印内容一致；默认跟随浏览器，右上角可切换 |
| 设计体验 | 清淡明确、大留白的视觉；全站统一 tokens 与组件库；手机/平板/桌面自适应 |
| 生态目标 | 建立可复用的「工具注册 + 生成引擎 + A4 渲染」框架，后续工具低成本接入 |

### 1.4 非目标（明确不做）

- ❌ 账号系统、云端存储、多端同步；
- ❌ 付费、订阅、广告、水印；
- ❌ 社区/作品分享平台、UGC 上传；
- ❌ AI 生图（首版）；照片转线稿（P2 再评估，且需本地处理）；
- ❌ 服务端批量导出、学情分析、班级管理；
- ❌ 提供受版权保护的教材原题、卡通 IP 线稿；
- ❌ 承诺训练效果（如「提升成绩」）。

> 产品无账号、无后端，**不采集个人数据**。因此指标分为「工程质量」「公开反馈」两类；若未来引入匿名统计，必须是可关闭、聚合、无个人标识的（P2 决策）。

| 指标 | 目标 |

## 4. 信息架构

### 4.1 站点地图

```
/                         主页面：全部生成子应用列表 + 使用指引 + 最近使用
/tools/coloring           涂色页生成器
/tools/math               口算页生成器
/tools/schulte            舒尔特方格生成器
/help/print               打印指南（A4、缩放、边距、校准）
/about                    关于 / 设计原则 / 隐私说明
/changelog                更新日志
（P1） /tools               全部子应用列表（工具多了以后）
```

主页面是应用入口，集中展示所有已注册的生成子应用；每个子应用对应一种独立生成能力，拥有独立页面与 URL。新增子应用只需注册，无需修改主页面。

### 4.2 全局导航

- 顶部：Logo（paper-maker）· 子应用（下拉/横向）· 打印指南 · 关于 · **语言切换（右上角，P0）**；
- 语言切换显示「中文 / English」（或「中 / EN」），桌面固定在顶栏右侧，移动端同样在顶栏右上角可见；
- 移动端：汉堡菜单；
- 页脚：GitHub 仓库 · 反馈 Issue · 隐私说明 · 许可。

### 4.3 子应用页布局（核心交互模式）

采用**「左参数、中预览、右操作」三段式**，移动端纵向堆叠：

```
┌────────────────────────────────────────────────────────────┐
│ paper-maker    子应用 ▾    打印指南    关于        [中/EN] │
├──────────────┬─────────────────────────────┬───────────────┤
│ 参数面板      │        A4 实时预览           │  打印 / 导出   │
│              │   ┌───────────────────┐     │               │
│ · 工具预设    │   │                   │     │ [打印 A4]      │
│ · 难度/规格   │   │   按 210×297mm     │     │ [导出 PDF]     │
│ · 排版        │   │   等比缩放渲染      │     │ [重新生成]     │
│ · 页眉页脚    │   │                   │     │ [随机种子 ▾]   │
│ · 答案页      │   └───────────────────┘     │ [打印校准页]   │
│ · 批量        │   预览缩放：50% / 75% / 100% │               │
├──────────────┴─────────────────────────────┴───────────────┤
│ 页脚：GitHub · 反馈 · 隐私 · MIT                             │
└────────────────────────────────────────────────────────────┘
```

> 图中右上角 `[中/EN]` 为全局语言切换（P0）：桌面与移动端均固定在顶栏右上角；切换不刷新页面、不重置当前参数与预览。

### 4.4 URL 设计

- 工具页使用**可分享的查询参数**，参数变化同步到 URL（用 `history.replaceState`，不产生历史堆积）；
- 参数包含 `seed`，打开链接可复现同一份内容；
- 路由方案（History vs Hash）由[技术方案](05-architecture.md)决定，但**必须保证 GitHub Pages 直接访问子路径不 404**。

## 5. 通用能力需求

> 所有工具共用。编号 G-xx，优先级 P0/P1/P2。

### G-01 主页面与子应用列表（P0）

- 主页面（`/`）是应用入口，**列出全部生成子应用**；每个子应用对应一种生成能力（如涂色页、口算页、舒尔特方格），后续新增子应用自动出现在列表；
- 每个子应用卡片包含：名称、一句话说明、示意图/缩略预览、适用标签（年级/年龄/训练类型）、「进入」按钮；
- 子应用列表由「工具注册表」驱动，新增子应用只需注册，**无需修改主页面代码**；
- 展示「最近使用」与「我的预设」（来自 localStorage）；
- 明确提示：无需登录、纯本地生成、免费、支持中英文；
- 子应用数量 ≥ 6 时，提供按名称/标签的搜索或筛选（P1）。

**验收**：从主页面到任一子应用 ≤ 1 次点击；注册新子应用后无需改主页面代码即可出现在列表；无 JS 时仍能看到列表与说明（渐进增强）；中英文下卡片文案完整、无溢出。

### G-02 子应用页三段式布局（P0）

- 参数区、预览区、操作区职责分离；移动端（< 900px）纵向堆叠，预览可折叠；
- 参数变更后预览**即时更新**（防抖 ≤ 150ms），不阻塞输入；
- 预览区固定显示纸张轮廓与尺寸标注（210 × 297 mm）。

### G-03 参数配置（P0）

- 参数控件：单选、多选、滑块、数字输入、开关、下拉；
- 每个参数提供**默认值**与**说明文字**（如「数值范围 100 以内 = 结果不超过 100」）；
- 提供工具预设（如口算「一年级上 / 二年级上」），一键套用；
- 参数非法时（如题量 0）即时提示并回退到合法值。

### G-04 随机种子与复现（P0）

- 每次生成显示种子（短字符串/数字），可复制；
- 通过 URL `seed` 或输入框设置种子，**同参数 + 同种子 = 同结果**（确定性生成）；
- 「重新生成」= 换随机种子；
- 「锁定种子」后可只改排版参数而不改变题目内容。

### G-05 A4 页面设置（P0）

- 纸张固定 A4（210×297mm），支持纵向/横向（首版工具均纵向）；
- 页边距预设：窄（10mm）/ 标准（15mm）/ 宽（20mm）/ 自定义；
- 页眉页脚开关：标题、姓名栏、日期栏、页码、页脚说明；
- 「省墨模式」：去底纹、去装饰边框、线稿纯黑；
- 所有尺寸以 mm 指定，预览按比例缩放。

### G-06 打印（P0）

- 点击「打印 A4」调用浏览器打印；
- 打印时隐藏所有 UI，仅输出纸张内容；
- 打印样式使用 `@page { size: A4; margin: 0 }` + 内部留白控制，避免双重边距；
- 打印前给出 3 条提示：选择 A4、缩放 100%（不选「适应页面」）、关闭浏览器页眉页脚。

### G-07 导出 PDF（P0 基础 / P2 增强）

- **P0**：所有子应用提供「下载 PDF」按钮，调用浏览器打印对话框，用户选择「另存为 PDF」导出，保持矢量；
- 打印与 PDF 均输出当前全部张数（含答案页）；
- **P2**：评估 `pdf-lib` 在客户端直接导出精确 A4 矢量 PDF（不引入 html2canvas 栅格化路线）。

### G-08 多张生成（P0）

- **所有子应用统一提供「生成张数」**：1 / 2 / 3 / 5 / 10 张；
- **每张内容**：可选「每张不同」（派生种子生成不同内容）或「每张相同」（打印多份同一内容）；
- 打印与「下载 PDF」均按当前张数输出全部页面；口算页的答案页随每张练习页配套输出；
- 批量必须**分页正确**，不得出现半页题目或空白页；
- 分享链接默认携带基础种子，可复现第一张（P1 完善全部参数）。

### G-09 答案页（P0，口算/数独类）

- 「附带答案页」开关：开启后答案单独成页，排在练习页之后；
- 「仅打印练习页」快捷操作（打印范围提示）；
- 答案页版式紧凑、字号可小，标题明确标注「答案」。

### G-10 本地预设（P1）

- 保存当前参数为命名预设（localStorage）；
- 支持「最近使用」「收藏」；
- 明示：数据仅存本机，清除浏览器数据即丢失。

### G-11 分享链接（P0 基础上 P1 完善）

- 复制当前参数 + 种子的分享链接；
- 打开链接还原全部参数并生成相同内容；
- 链接尽量短（参数键名简短，省略默认值）。

### G-12 响应式（P0）

- 断点：手机 < 640px、平板 640–1024px、桌面 > 1024px；
- 手机上参数区可操作、预览可缩放查看；打印引导以桌面为主（手机打印需说明）；
- 触屏控件 ≥ 44×44px。

### G-13 中英文切换（P0）

- 支持 **简体中文（zh-CN）** 与 **英文（en）** 两套完整界面文案；P1 再扩展其他语言；
- **语言切换入口固定在页面右上角**：桌面为顶栏右侧；移动端顶栏右上角同样可见，可收纳为图标/菜单；
- **默认语言跟随浏览器**：首次访问读取 `navigator.languages` / `navigator.language`，`zh*` → 中文，`en*` → English，其他语言 → English（兜底策略可在 M1 前调整）；
- 用户手动切换后记住选择（localStorage），后续访问优先使用用户选择；浏览器语言变化不覆盖手动选择；
- **切换不刷新页面、不丢失当前参数/种子/预览**，界面与 A4 预览立即更新；
- **打印内容同步切换**：页眉页脚、标题、姓名/日期栏、答案页标注、训练说明等所有印刷文字随当前语言；数字、算式等语言无关内容不变；
- 切换后同步更新 `<html lang>`、页面 `<title>` 与元描述；
- 语言切换控件可键盘操作、可被屏幕阅读器识别；不使用国旗图标暗示国家；
- 所有界面字符串进入 i18n 文案表，**禁止组件内硬编码中文/英文**；
- 分享链接可选携带 `lang` 参数（P1），打开时优先于本地设置。

**验收**：浏览器语言分别为 zh-CN、en-US、fr-FR 首次访问，默认语言分别为中文、英文、英文；手动切到 EN 后刷新仍为 EN；切换语言后当前子应用参数与预览内容不重置；两种语言下所有页面与打印样张均无缺失文案、无溢出。

### G-14 无障碍（P0 基础 / P1 完善）

- 键盘可完成全部参数配置与打印；
- 表单控件有关联 label；对比度符合 WCAG AA；
- 预览内容提供文本替代描述（如「5×5 舒尔特方格，数字 1–25」）；
- 不使用仅靠颜色传达信息的设计（打印本身是黑白场景）。

### G-15 离线与 PWA（P2）

- 首次访问后可离线使用（Service Worker 缓存静态资源）；
- 可「添加到主屏幕」；
- 离线时功能完整（生成与打印均本地完成）。

### G-16 打印校准页与指引（P0）

- 提供一张「100mm 标尺校准页」：打印后用尺子量，判断是否被缩放；
- 打印指南页说明 A4、缩放、边距、浏览器差异；
- 工具页打印按钮旁提供「打印指南」入口。

### G-17 错误处理与兼容提示（P0）

- 生成失败（超时/参数冲突）给出可操作提示，不白屏；
- 检测到不支持打印样式的旧浏览器时提示升级；
- 任何错误不丢失用户已填参数。

### G-18 统一设计系统与自适应（P0）

- 全站使用**同一套设计 tokens**（色彩、字体、间距、圆角、阴影、动效），见[设计系统](07-design-system.md)；
- 所有设置/选择类组件（按钮、输入、数字、单选、复选、开关、滑块、下拉、分段控件、语言切换）来自**同一共享组件库**，外观、尺寸、七态、交互完全一致；
- **禁止子应用自定义控件样式**：子应用仅可定义内容渲染区域（SVG 线稿、方格、A4 预览纸张）与参数区布局组合；
- 视觉风格：清淡明确、大留白；中性色 + 单一强调色；无渐变/重阴影/大面积色块；
- 响应式：手机 <640px、平板 640–1023px、桌面 ≥1024px；支持横竖屏；无横向滚动；触控目标 ≥ 44×44px；输入字号 ≥ 16px（移动端）；
- 提供开发用 `/styleguide` 组件示例页与视觉回归测试，作为一致性验收依据。

**验收**：任意两个子应用同类控件一致；360 / 768 / 1440 三档无横向滚动；样式检查 0 处子应用私有控件样式；中英文下均无溢出。

## 8. 交互与视觉原则

> 完整规范（tokens、布局、组件、断点、验收）见[设计系统与视觉规范](07-design-system.md)，本节为 PRD 层约束。

1. **打印结果即产品**：所有设计决策以纸面效果为准；屏幕上不过度装饰。
2. **清淡明确**：低饱和中性色 + 单一强调色；无渐变、重阴影、大面积色块；层级靠字号、间距与留白表达。
3. **大留白**：页面左右留白、区块间距、卡片内边距按下限执行（见设计系统 §3.3）；留白是版面的一部分，不用边框填满屏幕。
4. **全站一致**：所有子应用共用同一套设计 tokens 与共享组件库；设置/选择类组件的外观、尺寸、状态、交互完全一致，**不允许子应用各自实现控件或改造样式**。
5. **自适应**：手机（<640px）、平板（640–1023px）、桌面（≥1024px）三档布局；无横向滚动；触控目标 ≥ 44×44px；手机可完成全部配置与打印引导。
6. **预览拟真**：预览按 mm 等比渲染，带纸张边界与页边距可视化，所见即所得。
7. **默认即可用**：每个子应用打开即有一份合理默认内容，用户不调参也能直接打印。
8. **参数可解释**：每个参数附一句话说明与效果示例，避免「复杂度 3」这种黑话。
9. **无障碍与可逆**：键盘可完成全流程、焦点可见、对比度 AA；重新生成前可回到上一份（P1）。

## 10. 数据与隐私

- **不收集任何个人数据**；无 Cookie 追踪、无第三方分析脚本。
- 本地存储仅用于：最近使用、用户预设、上次参数。可在「关于/隐私」页一键清除。
- 分享链接中的参数不含任何个人标识（除非用户自行填写姓名栏，且姓名只存在 URL 中，不上传）。
- 若未来引入访问统计：必须匿名聚合、可关闭、在前端明示；默认关闭或不做。
- 打印内容不上传、不缓存到服务器。

## 11. 验收标准

### 11.1 通用 Definition of Done（每个工具 P0）

- [ ] 默认参数下打开即可打印，无需任何配置；
- [ ] 所有 P0 参数可调，且预览在 150ms 内更新；
- [ ] 种子可复现：同参数 + 同种子结果完全一致；
- [ ] A4 打印无裁切、无缩放、无多余页眉页脚（按打印指南设置）；
- [ ] 手机端可完成参数配置与预览；
- [ ] 中英文两套界面与打印样张通过验收（默认跟随浏览器、右上角切换、切换不丢参数、无缺失文案/溢出）；
- [ ] 三档断点（360 / 768 / 1440）视觉检查通过：无横向滚动、留白与控件尺寸符合设计规范；
- [ ] 任意两个子应用同类控件外观一致，无子应用私有控件样式；
- [ ] 多张生成：张数、每张不同/相同、打印/PDF 页数与预览一致；
- [ ] 键盘可完成全部操作；
- [ ] Lighthouse 桌面 Performance / Accessibility ≥ 90；
- [ ] 单元测试覆盖生成引擎核心路径；
- [ ] 打印验收清单通过（见[打印规范](03-print-spec.md#10-打印验收清单)）。
