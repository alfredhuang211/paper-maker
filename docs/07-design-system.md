# 07 · 设计系统与视觉规范

> 版本：v0.3 · 状态：草案 · 日期：2026-11-09
> 关联：[PRD](02-prd.md) · [打印规范](03-print-spec.md) · [技术方案](05-architecture.md)

## 0. 适用范围

本文是 paper-maker **全站唯一**的视觉与交互规范。主页面、所有子应用、打印指南、关于页、弹层与提示，一律遵守本规范。

**硬性规则**：子应用不得拥有自己的控件样式；所有设置/选择类组件必须来自同一套共享组件库，并使用同一套设计 tokens。子应用只允许定义「生成内容的渲染区域」（如 SVG 线稿、舒尔特网格、A4 预览纸张）及参数区的布局组合。

---

## 1. 设计目标与关键词

| 关键词 | 含义 | 反例（不做） |
| --- | --- | --- |
| **清淡** | 低饱和中性色、单一强调色、无重阴影/渐变/大面积色块 | 彩色渐变按钮、彩色卡片墙、重投影 |
| **明确** | 层级清晰、文案直白、主操作唯一、状态可见 | 多重主按钮、图标含义不明、隐藏操作 |
| **留白** | 大间距、少边框、内容呼吸感；留白是版面的一部分 | 密集表单、卡片套卡片、贴边内容 |
| **一致** | 全站同一 tokens + 同一组件库；同类控件外观/行为完全相同 | 每个子应用各写一套按钮/开关 |
| **自适应** | 手机/平板/桌面/横竖屏均可用；打印版式独立 | 只做桌面、移动端横向滚动 |
| **内容优先** | 屏幕为生成与预览服务，纸面结果才是产品 | 花哨动效、装饰性插画喧宾夺主 |

---

## 2. 设计原则

1. **一屏一个主操作**：工具页的主操作是「打印 A4」；其余为次级/文字按钮。
2. **控件即规范**：所有表单控件由共享组件库提供，禁止子应用复制或重写样式。
3. **留白优先于分隔线**：优先用间距分组，其次用浅色分隔线，避免满屏边框。
4. **状态可读**：默认、悬停、聚焦、按下、禁用、加载、错误七态必须完整且一致。
5. **移动端不降级**：手机端可完成全部配置与打印引导；不是「桌面版的缩水页」。
6. **打印与屏幕分离**：屏幕风格（颜色、阴影、圆角）不得进入打印内容；纸面始终黑白线稿。

## 3. 设计 tokens

> 实现时以 `src/styles/tokens.css`（CSS 自定义属性）为唯一来源；组件与页面只能引用 token，禁止硬编码色值/间距/圆角。

### 3.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#FAFAF8` | 页面背景（暖白，降低屏幕刺眼感） |
| `--color-surface` | `#FFFFFF` | 卡片、面板、输入框底色 |
| `--color-surface-muted` | `#F4F4F1` | 次级区域、预览区背景 |
| `--color-ink` | `#1F2328` | 主文本 |
| `--color-ink-secondary` | `#5B6470` | 次级文本、说明 |
| `--color-ink-muted` | `#8A929C` | 占位符、禁用文本 |
| `--color-line` | `#E6E4DF` | 分隔线、卡片描边 |
| `--color-line-strong` | `#D4D2CB` | 输入框边框、强调分隔 |
| `--color-accent` | `#2563EB` | 主操作、链接、选中态（**每屏使用面积 < 5%**） |
| `--color-accent-soft` | `#EFF4FF` | 选中项浅底、聚焦光晕 |
| `--color-success` | `#1F8A55` | 成功提示 |
| `--color-warning` | `#B26B00` | 警示提示 |
| `--color-danger` | `#C43C3C` | 错误、危险操作 |

规则：

- 不使用渐变、彩色阴影、大面积色块；
- 信息不依赖颜色单独传达（同时用文字/图标/线型）；
- 打印内容强制纯黑 `#000` + 白底，与屏幕色板解耦。

### 3.2 字体

| 项 | 规范 |
| --- | --- |
| 中文 | Noto Sans SC（OFL，子集化） |
| 英文/数字 | Inter → system-ui → -apple-system，回退 PingFang SC / Microsoft YaHei |
| 字重 | 400（正文）/ 500（强调）/ 600（标题），不用 700+ |
| 字号阶梯 | 12 / 14 / 16 / 18 / 20 / 24 / 32 / 40 px |
| 行高 | 正文 1.6；标题 1.25；表单 1.4 |
| 数字 | 统计/页眉/答案使用 tabular 数字 |
| 字间距 | 中文 0；英文标题 -0.01em；不使用大写长文本 |

### 3.3 间距（4px 基数）

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `--space-1` | 4px | 图标与文字、紧凑内边距 |
| `--space-2` | 8px | 标签与控件、按钮内间距 |
| `--space-3` | 12px | 表单行内间距 |
| `--space-4` | 16px | 卡片内边距（移动）、表单组间距 |
| `--space-5` | 24px | 卡片内边距（桌面）、区块间距 |
| `--space-6` | 32px | 面板间距、桌面栅格间距 |
| `--space-7` | 48px | 区块间距（移动） |
| `--space-8` | 64px | 区块间距（平板） |
| `--space-9` | 96px | 区块间距（桌面）、首屏留白 |

**留白底线**

- 页面左右留白：手机 20px / 平板 32px / 桌面 48px / 宽屏 64px；
- 内容最大宽度 **1200px**（阅读型页面 720px）；
- 主页面首屏顶部留白 ≥ 64px（桌面）/ 40px（手机）；
- 卡片内边距 20–32px；卡片间距 16–24px；
- 任意两个带边框容器**不得嵌套超过 2 层**；
- 表单组之间 ≥ 24px；一组内字段间距 16px。

### 3.4 圆角、描边、阴影、动效

| 项 | 规范 |
| --- | --- |
| 圆角 | 小 6px（徽标/小控件）、中 10px（输入/按钮）、大 14px（卡片/面板）、胶囊 999px（分段/标签） |
| 描边 | 1px `var(--color-line)`；输入框聚焦时 1px accent + 2px 光晕 |
| 阴影 | 仅浮层（下拉/弹层/Toast）：`0 8px 24px rgba(0,0,0,.08)`；卡片禁止重投影，用描边+留白区分 |
| 动效 | 150–200ms `ease-out`；只做透明度/位移/尺寸；遵守 `prefers-reduced-motion`；不做装饰性动画 |

### 3.5 图标

- 线性图标，1.5px 描边，20/24px，风格统一（建议 Lucide，ISC 许可）；
- 图标只作辅助，必须配文字或 `aria-label`；
- 不使用彩色/拟物/emoji 作为功能图标。

## 4. 布局规范

### 4.1 主页面（子应用列表）

```
┌──────────────────────────────────────────────────────────────┐
│  paper-maker                                  [中文 / EN]    │  ← 顶栏 64px
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   把练习纸，变成一次打印。                                    │  ← 大标题 40px
│   选择下面的小工具，调好参数，打印 A4。                        │  ← 副标题 18px
│                                                              │
│   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐    │
│   │   涂色页      │   │   口算页      │   │  舒尔特方格   │    │  ← 3 列 / 间距 24
│   │   说明…       │   │   说明…       │   │  说明…        │    │
│   │            → │   │            → │   │            → │    │
│   └──────────────┘   └──────────────┘   └──────────────┘    │
│                                                              │
│   （更多子应用自动出现在这里）                                │
└──────────────────────────────────────────────────────────────┘
```

- 内容最大宽 1200px，居中；卡片栅格：桌面 3 列 / 平板 2 列 / 手机 1 列；
- 卡片高度一致，说明文字最多 2 行；整卡可点击，悬停仅轻微上浮或描边加深；
- 顶部留白充足，不堆叠「公告/横幅/广告」。

### 4.2 子应用页

桌面（≥1024px）：三栏，间距 32px，**预览区是视觉中心**。

```
┌──────────────────────────────────────────────────────────────────────┐
│ paper-maker       子应用 ▾        打印指南        关于      [中文/EN] │
├───────────────┬──────────────────────────────────┬───────────────────┤
│  设置           │          A4 预览                  │  打印              │
│  320px         │          flex: 1                  │  240px            │
│                │   ┌──────────────────────┐        │  [打印 A4]         │
│  分组 1        │   │                      │        │  [导出 PDF]        │
│  分组 2        │   │   210×297mm 纸张      │        │  [重新生成]        │
│  分组 3        │   └──────────────────────┘        │  种子 / 校准页      │
│                │   缩放 50% / 75% / 100%           │                   │
└───────────────┴──────────────────────────────────┴───────────────────┘
```

平板（640–1023px）：两栏（设置 280px + 预览），操作按钮移入预览区上方工具条；或按宽度纵向堆叠。

手机（<640px）：

- 单列：顶栏（含语言切换）→ 预览（可折叠，默认展开，按屏宽缩放）→ 设置（手风琴分组）→ **底部固定操作栏**（打印 / 重新生成）；
- 底部操作栏预留 `env(safe-area-inset-bottom)`；
- 表单控件高度 ≥ 44px；输入框字号 ≥ 16px（避免 iOS 自动放大）；
- 不出现横向滚动；预览按宽度等比缩放，可双指缩放查看（P1）。

### 4.3 打印

打印样式与屏幕响应式完全解耦；纸张固定 210×297mm，见[打印规范](03-print-spec.md)。屏幕端任何断点变化都不得影响打印分页与 mm 布局。

## 5. 共享组件库

> 所有组件放在 `src/components/ui/`，统一 API、统一状态、统一尺寸；子应用不得复制实现。

### 5.1 组件清单（P0）

| 类别 | 组件 | 要求 |
| --- | --- | --- |
| 按钮 | Button、IconButton | primary / secondary / ghost / danger；尺寸 sm 32 / md 40 / lg 48（移动端 44+）；七态完整；加载态禁用并显示进度 |
| 表单 | Field（label/help/error 包装）、TextInput、NumberInput、Textarea（标题用） | label 必须可见；错误内联；帮助文本 12px；控件高度 40 / 44 |
| 选择 | Select、RadioGroup、Checkbox、Switch、SegmentedControl | 选项间距一致；选中态仅用 accent 描边/浅底，不做彩色填充 |
| 数值 | RangeSlider（带数值输入） | 滑块与数字联动；步进与范围由参数 schema 决定 |
| 展示 | Card、Panel、Divider、Tag、Badge、Tooltip | 卡片统一 14px 圆角 + 1px 描边 + 20/24px 内边距 |
| 反馈 | Dialog、Toast、InlineAlert | 浮层统一阴影；Toast 自动消失；错误可操作 |
| 布局 | AppShell、PageHeader、ToolLayout、StickyActionBar | 桌面/平板/手机三套布局行为 |
| 业务 | LanguageSwitcher、SeedField、PreviewFrame、PrintActions、PresetSelect、MarginSelector | 跨子应用完全复用；不允许子应用改外观 |

### 5.2 组件硬性规则

1. 颜色、间距、圆角、阴影、字号**只能**引用 tokens；
2. 同类控件在不同子应用中的宽度、高度、内边距、字号、圆角必须一致；
3. 不新增「看起来差不多」的组件；缺能力时扩展共享组件，而不是在子应用里私有实现；
4. 每个组件必须具备键盘操作、焦点样式、禁用态、错误态；
5. 不允许子应用覆盖组件内部样式（禁止 `!important`、禁止选择器穿透）；仅允许通过 props 控制尺寸变体；
6. 子应用特有样式只作用于内容画布（SVG / 打印纸张）与布局栅格。

### 5.3 表单布局

- 标签在上、控件在下（移动端与桌面一致），不使用仅 placeholder 的标签；
- 一行一个字段；相关选择项（如单选的 3 个选项）可同排；
- 错误信息紧贴控件下方，红色 + 图标 + 文案；
- 参数分组标题使用 14px/500 的次级标题，不做彩色标题。

## 6. 响应式规范

### 6.1 断点

| 名称 | 宽度 | 典型设备 |
| --- | --- | --- |
| Mobile | < 640px | 手机竖屏（360–430） |
| Tablet | 640–1023px | 平板竖屏/手机横屏 |
| Desktop | ≥ 1024px | 笔记本/台式 |
| Wide | ≥ 1440px | 大屏（内容仍限 1200px，居中） |

### 6.2 行为矩阵

| 区域 | Mobile | Tablet | Desktop |
| --- | --- | --- | --- |
| 顶栏 | Logo + 语言切换 + 菜单（折叠） | Logo + 导航 + 语言切换 | 完整导航 + 语言切换 |
| 主页面卡片 | 1 列 | 2 列 | 3 列 |
| 子应用布局 | 单列 + 底部固定操作栏 | 两栏（设置 + 预览） | 三栏（设置 / 预览 / 操作） |
| 设置面板 | 手风琴分组 | 常展开 | 常展开 |
| 预览 | 按宽缩放、可折叠 | 按宽缩放 | 100% 内的适配缩放 |
| 操作 | 底部固定栏（打印/重新生成） | 工具条 | 右侧操作栏 |
| 触控目标 | ≥ 44×44px | ≥ 44×44px | ≥ 40×40px |

### 6.3 响应式硬性要求

- 360px 宽度起可用；**任何断点无横向滚动**；
- 支持横竖屏切换不丢失参数；
- 手机端可完成「选子应用 → 调参 → 预览 → 打印/存 PDF」全流程；
- 200% 浏览器缩放不出现内容截断（WCAG 1.4.10）；
- 打印样式不受断点影响；
- 触控目标间距 ≥ 8px。

## 7. 可访问性（与设计系统合并）

- 文本对比度 ≥ 4.5:1，大字号 ≥ 3:1；
- 焦点环可见（2px accent，offset 2px），不依赖 `:hover`；
- 所有控件有可读 label；图标按钮有 `aria-label`；
- 错误不只靠颜色；Toast 使用 `aria-live`；
- 尊重 `prefers-reduced-motion`；
- 语言切换后 `<html lang>` 同步。

## 8. 一致性治理

| 手段 | 做法 | 门槛 |
| --- | --- | --- |
| tokens 单一来源 | `tokens.css`；禁止页面硬编码色值/间距/圆角 | lint 0 处硬编码 |
| 共享组件库 | 所有控件来自 `components/ui` | 子应用 0 个私有控件实现 |
| 组件示例页 | 开发环境 `/styleguide` 展示全部组件七态 | M1 交付 |
| 视觉回归 | Playwright 截图：3 断点 × 2 语言 × 关键页面 | 差异需评审 |
| 设计走查 | M2/M5 各一次全站走查 | 检查清单全过 |
| Code Review | PR 模板增加「是否复用组件 / 是否用 tokens」勾选 | 每次 PR |

## 10. 非目标与待定

**非目标（首版）**

- 不做每个子应用独立主题/皮肤；
- 不做深色模式（P2 评估，tokens 预留）；
- 不做密集/紧凑模式；
- 不使用插画、照片、装饰性大图；
- 不做复杂动效/视差。
